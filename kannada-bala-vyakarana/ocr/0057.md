ಮೇಲಿನ ವಾಕ್ಯಗಳಲ್ಲಿ ಕಂಡುಬರುವ ಕ್ರಿಯಾಸದಗಳಿಂದ ಕ್ರಿಯೆ  
ಹಿಂದೆ ನಡೆದಿರುವುದಾಗಿ ತಿಳಿದು ಬರುವ ಕಾರಣ, ಈ ಕ್ರಿಯಾಪದಗಳಿಗೆ  
ಭೂತಕಾಲದ ಕ್ರಿಯಾಸದಗಳೆಂದು ಹೆಸರು. ಆದುದರಿಂದ ಮೇಲಿನ ಕ್ರಿಯಾ  
ಪದಗಳಲ್ಲಿರುವ ಅನು, ಅಳು, ಇತ್ತು ಎ, ಎನು, ಅಕ್ಕು, ಅವು, ಇರಿ, ಎವು—  
ಎಂಬುವು ಭೂತಕಾಲದ ಆಖ್ಯಾತ ಪ್ರತ್ಯಯಗಳು.  

(3) ಭವಿಷ್ಯತ್‌ ಕಾಲದ ಕ್ರಿಯಾಸದ ರೂಪಗಳು : ಮುಂದೆ  
.ಬರುವ 'ಕಾಲದ ಕ್ರಿಯೆ ನಡೆಯುವುದನ್ನು ತಿಳಿಸುವ ಕ್ರಿಯಾಪದವು  
ಭವಿಷ್ಯತ್‌ ಕಾಲದ ಕ್ರಿಯಾಪದವೆನಿಸುವುದು.  

ಈ ಕೆಳಗೆ ಕೊಟ್ಟಿರುವ ವಾಕ್ಯಗಳಲ್ಲಿ ಕಂಡುಬರುವ ಕ್ರಿಯಾಸದಗಳನ್ನು  
ಗಮನಿಸಿರಿ.  

(ಪ್ರ.ಪು.ಏ.).... ಅನನು ಓಡುವನು — ಓಡು + ವ + ಅನು  
(ಸ್ತ್ರ.ಸ್ತ್ರೀ ಐ)... ಅವಳು ಓಡುವಳು — ಓಡು + ವ + ಅಳು  
(ಪ್ರ.ನ.ಏ. ).... ಅದು ಓಡುವುದು — ಓಡು + ವ + ಉದು  
(ಮು.ವಾ.ಏ.).... ನೀನು ಓಡುವೆ — ಓಡು + ವ + ಎ  
(ಉ.ವಾ.ಏ.).... ನಾನು ಓಡುವೆನು — ಓಡು + ವೆ + ಎನು  
(ಪ್ರ.ವಾ ಬ.).... ಅನರು ಓಡುವರು — ಓಡು + ವ + ಅರು  
(ಸ್ರ.ನ.ಬ. ).... ಅವು ಓಡುವುವು — ಓಡು + ನ + ಉವು  
(ಮು.ವಾ.ಬ')..., ನೀವು ಓಡುನಿರಿ — ಓಡು + ವ + ಇರಿ  
(ಉ.ವಾ.ಬ).... ನಾವು ಓಡುವೆವು — ಓಡು + ನ + ಎವು  

ಇಲ್ಲಿ ಒಂಭತ್ತು ಕ್ರಿಯಾಸದಗಳಿವೆ. ಈ ಕ್ರಿಯಾಸದಗಳಲ್ಲಿ “ಓಡು”  
ಧಾತುವಿನ ಮುಂದೆ ಎಲ್ಲ ಕಡೆಗೂ “ವ” ಎಂಬ ಪ್ರತ್ಯಯ ಬಂದಿದೆ ; ಈ  
ಪ್ರತ್ಯಯದ ಮುಂದೆ ಏಕವಚನದಲ್ಲಿ ಅನು, ಅಳು, ಉದು, ಎ, ಎನು—ಎಂಬ  
ಆಖ್ಯಾತ ಪ್ರತ್ಯಯಗಳೂ ಬಹುವಚನದಲ್ಲಿ ಅರು, ಉವು, ಇರಿ, ಎವು—  
ಎಂಬ ಆಖ್ಯಾತ ಪ್ರತ್ಯಯಗಳೂ ಬಂದಿವೆ.  

ಮೂಲ ಧಾತುನಿಗೂ ಆಖ್ಯಾತ ಪ್ರತ್ಯಯಕ್ಕೂ ನಡುವೆ ಬಂದಿರುವ “ವ”  
ಎಂಬುದು ಕಾಲಸೂಚಕ ಪ್ರತ್ಯಯ. ಇದು ಭವಿಷ್ಯತ್‌ ಕಾಲವನ್ನು ಸೂಚಿಸು.
