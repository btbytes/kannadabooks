ಸೂತ್ರ : ಸಂಧಿಕಾರ್ಯದಲ್ಲಿ ಪೂರ್ವಶಬ್ದದ ಅಂತ್ಯದಲ್ಲಿರುವ ಕ, ಚ,  
ಟ, ತ, ಪ ವ್ಯಂಜನಗಳಿಗೆ ಯಾವುದೇ ವರ್ಣ ಪರವಾದರೂ ಕ್ರಮವಾಗಿ ಗ, ಜ,  
ಡ, ದ, ಬ ವ್ಯಂಜನಗಳು ಆದೇಶಗಳಾಗಿ ಬರುವುದಾದರೆ ಅದು ಜಶ್ತ್ವ ಸಂಧಿ  
ಯೆನಿಸುವುದು.  

(೧) ಶ್ಚುತ್ವ ಸಂಧಿ :  

ಈ ಉದಾಹರಣೆಗಳನ್ನು ಗಮನಿಸಿ...  

(i) ಮನಸ್‌ + ಚಂಚಲ = ಮನಶ್‌ + ಚಂಚಲ = ಮನಶ್ಚಂಚಲ  
(ಸಕಾರಕ್ಕೆ ಚಕಾರ ಪರವಾಗಿದ್ದು ಸಕಾರಕ್ಕೆ ಶಕಾರಾದೇಶವಾಗಿದೆ)  

(ii) ತಕಾರ + ಚಕಾರ = ತಕಾರ + ಚಕಾರ = ತಕಾರಚಕಾರ  
(ತಕಾರಕ್ಕೆ ಚಕಾರ ಪರವಾಗಿದ್ದು ತಕಾರಕ್ಕೆ ಚಕಾರಾದೇಶವಾಗಿದೆ)  

(iii) ಬೃಹತ್‌ + ಛತ್ರ = ಬೃಹಚ್‌ + ಛತ್ರ = ಬೃಹಚ್ಛತ್ರ  
(ತಕಾರಕ್ಕೆ ಛಕಾರ ಪರವಾಗಿದ್ದು ತಕಾರಕ್ಕೆ ಚಕಾರಾದೇಶವಾಗಿದೆ)  

(iv) ಮನಸ್‌ + ಶುದ್ಧಿ = ಮನಶ್‌ + ಶುದ್ಧಿ = ಮನಶ್ಶುದ್ಧಿ  
(ಸಕಾರಕ್ಕೆ ಶಕಾರ ಪರವಾಗಿದ್ದು ಸಕಾರಕ್ಕೆ ಶಕಾರಾದೇಶವಾಗಿದೆ)  

—ಇವು ಶ್ಚುತ್ವ ಸಂಧಿಗೆ ಉದಾಹರಣೆಗಳು. ಶ್ಚುತ್ವ ಸಂಧಿ  
ಯಾಗುವ ಸಂದರ್ಭಗಳನ್ನು ಕೆಳಗೆ ಕೊಟ್ಟಿರುವ ಸೂತ್ರದಿಂದ ತಿಳಿಯಬಹುದು.  

ಸೂತ್ರ : ಪೂರ್ವ ಪದದ ಅಂತ್ಯದಲ್ಲಿ ಸಕಾರವಾಗಲೀ ತವರ್ಗದಲ್ಲಿನ  
ಯಾವುದಾದರೊಂದು ವರ್ಣವಾಗಲೀ ಇದ್ದು, ಆ ವರ್ಣಗಳಿಗೆ ಶಕಾರವಾಗಲೀ  
ಚವರ್ಗದಲ್ಲಿನ ಯಾವುದಾದರೊಂದು ವರ್ಣವಾಗಲೀ ಪರವಾದಾಗ, ಸಕಾರಕ್ಕೆ  
ಶಕಾರವೂ ತವರ್ಗಕ್ಕೆ ಚವರ್ಗವೂ ಆದೇಶಗಳಾಗಿ ಬರುವುದಾದರೆ ಅದು  
ಶ್ಚುತ್ವ ಸಂಧಿಯೆನಿಸುವುದು.  

(೨) ಅನುನಾಸಿಕ ಸಂಧಿ :  

ಈ ಉದಾಹರಣೆಗಳನ್ನು ಗಮನಿಸಿ—  

ವಾಕ್‌ + ಮಯ = ವಾಙ್‌ + ಮಯ = ವಾಙ್ಮಯ  
(ಕಕಾರಕ್ಕೆ ಮಕಾರ ಪರವಾಗಿದ್ದು ಙ ಕಾರ ಆದೇಶವಾಗಿದೆ)
