ಸೂತ್ರ : ಸಂಧಿಕಾರ್ಯದಲ್ಲಿ ಪೂರ್ವಶಬ್ದದ ಅಂತ್ಯದಲ್ಲಿರುವ ಕ, ಚ,  
ಟ, ತ, ಪ ವ್ಯಂಜನಗಳಿಗೆ ಯಾವುದೇ ವರ್ಣ ಪರವಾದರೂ ಕ್ರಮವಾಗಿ ಗ್ರ, ಜ್ಞ,  
ಡ, ದ, ಬ ವ್ಯಂಜನಗಳು ಆದೇಶಗಳಾಗಿ ಬರುವುದಾದರೆ ಅದು ಜಶ್ತ ಟ ಸಂಧಿ  
ಯೆನಿಸುವುದು.  

(೧) ಶ್ಚುತ್ತ ಸಂಧಿ :  

ಈ ಉದಾಹರಣೆಗಳನ್ನು ಗಮನಿಸಿ...  

(i) ಮನಸ್‌ + ಚಂಚಲ = ಮನಶ್‌ + ಚಂಚಲ = ಮನಶ್ಚಂಚಲ  
(ಸಕಾರಕ್ಕೆ ಚಕಾರ ಪರವಾಗಿದ್ದು ಸಕಾರಕ್ಕೆ ಶಕಾರಾದೇಶವಾಗಿದೆ)  

(ii) ತಕಾರ + ಚಕಾರ = ತಕಾರ + ಚಕಾರ = ತಕಾರಚಕಾರ  
(ತಕಾರಕ್ಕೆ ಚಕಾರ ಪರವಾಗಿದ್ದು ತಕಾರಕ್ಕೆ ಚಕಾರಾದೇಶವಾಗಿದೆ)  

(iii) ಬೃಹತ್‌ + ಛತ್ರ = ಬೃಹಚ್‌ + ಛತ್ರ = ಬೃಹಚ್ಛತ್ರೆ  
(ಶಕಾರಕ್ಕೆ ಛಕಾರ ಪರವಾಗಿದ್ದು ತಕಾರಕ್ಕೆ ಚಕಾರಾದೇಶವಾಗಿದೆ)  

(iv) ಮನಸ್‌ + ಶುದ್ಧಿ = ಮನಶ್‌ + ಶುದ್ಧಿ = ಮನಶ್ಯುದ್ಧಿ  
(ಸಕಾರಕ್ಕೆ ಶಕಾರ ಪರವಾಗಿದ್ದು ಸಕಾರಕ್ಕೆ ಶಕಾರಾದೇಶವಾಗಿದೆ)  

—ಇವು ಶ್ಚುತ್ತ ಟೆ ಸಂಧಿಗೆ ಉದಾಹರಣೆಗಳು. ಶ್ಚುತ್ತ ಟ ಸಂಧಿ  
ಯಾಗುವ ಸಂದರ್ಭಗಳನ್ನು ಕೆಳಗೆ ಕೊಟ್ಟಿರುವ ಸೂತ್ರದಿಂದ ತಿಳಿಯಬಹುದು.  

ಸೂತ್ರ : ಪೂರ್ವ ಪದದ ಅಂತ್ಯನಲ್ಲಿ ಸಕಾರವಾಗಲೀ ತವರ್ಗದಲ್ಲಿನ  
ಯಾವುದಾದರೊಂದು ವರ್ಣವಾಗಲೀ ಇದ್ದು, ಆ ವರ್ಣಗಳಿಗೆ ಶಕಾರವಾಗಲೀ  
ಚವರ್ಗದಲ್ಲಿನ ಯಾವುದಾದರೊಂದು ವರ್ಣವಾಗಲೀ ಪರವಾದಾಗ, ಸಕಾರಕ್ಕೆ  
ಶಕಾರವೂ ತನರ್ಗಕ್ಕೆ ಚವರ್ಗವೂ ಆದೇಶಗಳಾಗಿ ಬರುವುದಾದರೆ ಅದು  
ಶ್ಚುತ್ತ ಟೆ ಸಂಧಿಯೆನಿಸುವುದು.  

(೨) ಅನುನಾಸಿಕ ಸಂಧಿ :  

ಈ ಉದಾಹರಣೆಗಳನ್ನು ಗಮನಿಸಿ—  

ವಾಕ್‌ + ಮಯುಎವಾಜಿ = ಮಯ + ವಾಜ್ಮಯ  
(ಕಕಾರಕ್ಕೆ ನಕಾರ ಪರವಾಗಿದ್ದು ಜ ಕಾರ ಆದೇಶವಾಗಿದೆ)
