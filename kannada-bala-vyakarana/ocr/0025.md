ಆಗುವುದು. ಹೀಗಾದಲ್ಲಿ ಸಂಧಿಪದವು ಅರ್ಥರಹಿತವಾಗುವುದು. ಇಂತಹ  
ಸಂದರ್ಭದಲ್ಲಿ ಎರಡೂ ಸ್ವರಗಳ ಮಧ್ಯೆ ಹೊಸದೊಂದು ಅಕ್ಷರ ಸೇರಿ ಸಂಧಿ-  
ಕಾರ್ಯವಾಗುವುದು. ಮೇಲಿನ ಉದಾಹರಣೆಯಲ್ಲಿ “ಯ್” ಎಂಬ ಅಕ್ಷರವು  
ಹೊಸದಾಗಿ ಬಂದು ಸೇರಿರುವುದನ್ನು ನೋಡಬಹುದು. ಹೀಗೆ  

ಸಂಧಿಕಾರ್ಯ ನಡೆಯುವಾಗ ಒಂದು ಅಕ್ಷರವು ಹೊಸದಾಗಿ  
ಬಂದು ಸೇರುವುದಕ್ಕೆ “ಆಗಮ ಸಂಧಿ” ಎಂದು ಹೆಸರು.  

ವಿವರಣೆ : ಮೇಲಿನ ಉದಾಹರಣೆಯಲ್ಲಿ ಯ-ಕಾರವು ಹೊಸದಾಗಿ  
ಬಂದು ಸೇರಿದೆ; ಆದುದರಿಂದ ಇದನ್ನು ಯ-ಕಾರಾಗಮ ಸಂಧಿ ಎಂದು  
ಹೇಳುತ್ತೇವೆ.  

ಬಾಣ + ಅನ್ನು = ಬಾಣವನ್ನು ; ಇಲ್ಲಿ “ವ” ಕಾರವು ಹೊಸದಾಗಿ  
ಬಂದು ಸೇರಿ ಸಂಧಿಕಾರ್ಯವಾಗಿದೆ. ಇದು ವ-ಕಾರಾಗಮ ಸಂಧಿ.  

ಉದಾಹರಣೆ :  
□ ಯ-ಕಾರ ಆಗಮ ಸಂಧಿ □ ವ-ಕಾರ ಆಗಮ ಸಂಧಿ  
ಹಣೆ + ಅಲ್ಲಿ = ಹಣೆಯಲ್ಲಿ ; ಮಗು + ಇಗೆ = ಮಗುವಿಗೆ  
ಕೊಠಡಿ + ಇಂದ = ಕೊಠಡಿಯಿಂದ ; ಗೋ + ಇಂದ = ಗೋವಿಂದ  
ಮೈ + ಅನ್ನು = ಮೈಯನ್ನು ; ಹೆಣ + ಅನ್ನು = ಹೆಣವನ್ನು  
ದಾರಿ + ಅನ್ನು = ದಾರಿಯನ್ನು ; ಹೂ + ಇನ = ಹೂವಿನ  

(೩) ಆದೇಶ ಸಂಧಿ :  

ನಾವೆಲ್ಲರೂ ಜೊತೆಗೂಡಿ ಹೊರಡೋಣ ಎಂಬ ವಾಕ್ಯದಲ್ಲಿ ಜೊತೆಗೂಡಿ  
ಎಂಬ ಸಂಧಿ ಪದವನ್ನು ಬಿಡಿಸಿ ನೋಡೋಣ.  

ಜೊತೆ + ಕೂಡಿ = ಜೊ + (ತ್ + ಎ) + (ಕ್ + ಊ) + ಡಿ  
ಜೊತೆಗೂಡಿ = ಜೊ + (ತ್ + ಎ + ಗ್ + ಊ) + ಡಿ  

ಇಲ್ಲಿ ಸ್ವರದ ಮುಂದೆ ವ್ಯಂಜನ ಬಂದು ಸಂಧಿಕಾರ್ಯವಾಗುವುದನ್ನು  
ಕಾಣಬಹುದು. ಇಲ್ಲಿ ಉತ್ತರಾರ್ಥ ಭಾಗದ ಮೊದಲಿಗಿರುವ “ಕ್” ವ್ಯಂಜನಕ್ಕೆ  
ಬದಲಾಗಿ ಸಂಧಿ ಪದದಲ್ಲಿ “ಗ್” ವ್ಯಂಜನ ಸೇರಿ ಸಂಧಿಕಾರ್ಯವಾಗಿರುವುದು.
