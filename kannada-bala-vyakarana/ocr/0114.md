ಕುಂಟಿತ್ತು ಹೊಲಕ್ಕೆ ಊನ, ತನ್ನವರು ತನಗೇ ಊನ.  
ಕೆಂಬೂತ ನೋಡಿ ಕಾಗೆ ಪುಕ್ಕ ತರಕೊಂಡ ಹಾಗೆ.  
| ಗಾಣಗಿತ್ತಿ ಆಯ್ಯೋ ಅಂದ್ರೆ ನೆತ್ತಿ ತಂಪಾದೀತೆ?  
ಗಾಳಿ ಬಂದಾಗ ತೂರಿಕೋ. | |  

| ಗುಬ್ಬಿ ಮೇಲೆ ಬ್ರಹ್ಮಾಸ್ತ್ರ.  
| ಗಂಜಿ ಕುಡಿಯೋವಿಗೆ ಗಡ್ಡ ನೀವೋನೊಬ್ಬ.  
| ಜೋರ ಗುರು ಚಂಡಾಲ ಶಿಷ್ಯ.  

| ಚೀತೆಯಿಲ್ಲದವನಿಗೆ ಸಂತೇಲಿ ನಿದ್ದ.  

| ಜಟ್ಟಿ ಜಾರಿಬಿದ್ದರೊ ಮೀಸೆ ಮಣ್ಣಾಗಲಿಲ್ಲ. |  

ಜಾತಿಗೆ ಜಾತಿ ವೈರಿ, ನೀರಿಗೆ ಪಾಚಿ ವೆರಿ.  

| ತಕ್ಕಡೀಲಿ ಕಪ್ಪ ತೂಗಿದ ಹಾಗೆ. |  

| ತಾಳಿದವನು ಬಾಳಿಯಾನು.  

| ತೋಳ ಹೆಳ್ಳಕ್ಕೆ ಬಿದ್ದರೆ ಆಳಿಗೊಂದು ಕಲ್ಲು.  

ತುಂಬಿದ ಕೊಡ ತುಳುಕುವುದಿಲ್ಲ. |  

| ದಡ್ಡನಿಗೆ ದೊಣ್ಣೆ ಪೆಟ್ಟು, ಜಾಣನಿಗೆ ಮಾತಿನ ನೆಟ್ಟು.  

| ದಿನ ಸಾಯೋರಿಗೆ ಆಳೋರ್ಯಾರು? |  
| ದುಡ್ಡಿದ್ದವನೆ ದೊಡ್ಡ ವ್ರ. |  

| ದುಷ್ಟರ ಫಂಡರೆ ಜೂರ ಇರು.  

ದೂರದ ಬೆಟ್ಟ ನುಣ್ಣಗೆ.  

| ದೇವರು ವರ ಕೊಟ್ಟರೂ ಪೂಜಾರಿ ಕೊಡ.  

| ಧರ್ಮಕ್ಕೆ ದಟ್ಟಕೊಟ್ಟರೆ ಹಿತ್ತಲಿಗೆ ಹೋಗಿ ಮೊಳ ಹಾಕಿದನಂಕೆ.  
| ನಾಯಿ ಮೊಲೇಲಿ ಖಂಡುಗ ಹಾಲು.  

ನಾಯಿ ಬಾಲ ಡೊಂಕು.  
| ನೆಕ್ತುವ ನಾಯಿಗೆ ಲಿಂಗವೇನು? ನೀಠವೇನು?  
| ಪಾಪಿ ಸಮುದ್ರಕ್ಕೆ ದೆಗೀದರೂ ಮೊಣಕಾಲುದ್ದ ನೀರೇ.
