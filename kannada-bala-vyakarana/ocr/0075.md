ಕೃದಂತ ಭಾವನಾಮ :

ಕ್ರಿಯೆಯ ಭಾವವನ್ನು ತಿಳಿಸುವ ಶಬ್ದಗಳಿಗೆ ಕೃದಂತ ಭಾವನಾಮಗಳೆಂದು ಹೆಸರು; ಧಾತುಗಳ ಮೇಲೆ ಭಾವಾರ್ಥದಲ್ಲಿ ಕೃತ್‌ ಪ್ರತ್ಯಯಗಳು ಸೇರಿ ಕೃದಂತ ಭಾವನಾಮಗಳಾಗುವುದು.

ಉದಾಹರಣೆಗೆ, “ಕುಣಿ” ಎಂಬ ಧಾತುವಿನ ಮೇಲೆ “ತ” ಎಂಬ ಪ್ರತ್ಯಯ ಸೇರಲು “ಕುಣಿತ” ಎಂದಾಗುವುದು. “ಕುಣಿತ” ಎಂಬ ಶಬ್ದರೂಪವು ಕುಣಿಯುವ ಭಾವವನ್ನು ತಿಳಿಸುವುದು. ಆದುದರಿಂದ ಇದು ಕೃದಂತ ಭಾವನಾಮವೆನಿಸುವುದು.

□ ಕೆಳಗೆ ಕೊಟ್ಟಿರುವ ಉದಾಹರಣೆಗಳಿಂದ ಕೃದಂತ ಭಾವನಾಮಗಳ ಅಥವಾ ಭಾವ ಕೃದಂತಗಳ ಅರ್ಥ ಮತ್ತಷ್ಟು ಸ್ಪಷ್ಟವಾಗಿ ತಿಳಿದುಬರುವುದು.

| ಮೂಲ | ಭಾವಾರ್ಥದಲ್ಲಿ | ಭಾವ |
|------|----------------|------|
| ಧಾತು | ಕೃತ್‌ ಪ್ರತ್ಯಯ | ಕೃದಂತ |
| ನಡುಗು | + ಉಕ | ನಡುಕ |
| ನಗು | + ಎ | ನಗೆ |
| ನೋಡು | + ಟ | ನೋಟ |
| ಸೆಳೆ | + ತ | ಸೆಳೆತ |
| ತೊಡು | + ಇಗೆ | ತೊಡಿಗೆ |
| ತೊಡು | + ಗೆ | ತೊಡುಗೆ |
| ನಾಚು | + ಅಕೆ | ನಾಚಿಕೆ |
| ಉಳು | + ವುದು | ಉಳುವುದು |

ಕೃದಂತಾವ್ಯಯ :

ಧಾತುವಿನಿಂದ ಹುಟ್ಟಿ ಅವ್ಯಯದ ಲಕ್ಷಣಗಳನ್ನು ಹೊಂದಿರುವ ಶಬ್ದರೂಪಗಳಿಗೆ ಕೃದಂತಾವ್ಯಯಗಳು ಎಂದು ಹೆಸರು.

ಧಾತುಗಳ ಮೇಲೆ ಅಲು, ಅಲಿಕ್ಕೆ, ದು, ಇ, ದರೆ, ಉತ್ತ್ಯ, ಅದೆ, ಅ, ಉತ್ತ್ಯ, ಇರಲು-ಮೊದಲಾದ ಪ್ರತ್ಯಯಗಳು ಸೇರಲು ಕೃದಂತಾವ್ಯಯಗಳು.
