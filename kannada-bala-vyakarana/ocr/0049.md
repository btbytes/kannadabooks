ವಿಭಕ್ತಿ ಪ್ರತ್ಯಯಗಳನ್ನು ಎಂಟು ವಿಧಗಳಾಗಿ ವಿಂಗಡಿಸಬಹುದು.  
ಅವುಗಳು ಯಾವುವೆಂದರೆ—  

| ವಿಭಕ್ತಿ | ವಿಭಕ್ತಿ ಪ್ರತ್ಯಯ |
|---|---|
| (೧) ಪ್ರಥಮಾ ವಿಭಕ್ತಿ | ... | ಉ |
| (೨) ದ್ವಿತೀಯಾ ವಿಭಕ್ತಿ | ... | ಅನ್ನು |
| (೩) ತೃತೀಯಾ ವಿಭಕ್ತಿ | ... | ಇಂದ |
| (೪) ಚತುರ್ಥಿ ವಿಭಕ್ತಿ | ... | ಇಗೆ, ಗೆ, ಕ್ಕೆ, ಅಕ್ಕೆ |
| (೫) ಪಂಚಮೀ ವಿಭಕ್ತಿ | ... | ದೆಸೆಯಿಂದ |
| (೬) ಷಷ್ಠಿ ವಿಭಕ್ತಿ | ... | ಎಂ, ಅ |
| (೭) ಸಪ್ತಮೀ ವಿಭಕ್ತಿ | ... | ಅಲ್ಲಿ |
| (೮) ಸಂಬೋಧನಾ ವಿಭಕ್ತಿ | ... | ಎ, ಏ—ಇತ್ಯಾದಿ |  

**ವಿಭಕ್ತಿ ರೂಪಗಳು**  

(೧) ಪ್ರಥಮಾ ವಿಭಕ್ತಿ: ಪ್ರಥಮಾ ವಿಭಕ್ತಿ ಪ್ರತ್ಯಯ “ಉ” ಆಗಿದೆ.  
ಈ ವಿಭಕ್ತಿ ಪ್ರತ್ಯಯವು ಸಾಮಾನ್ಯವಾಗಿ ಕರ್ತೃಪದದ ಮೇಲೆ ಬರುವುದು.  

ಉದಾ:  
1. ಸೂರ್ಯನು ಪೂರ್ವದಲ್ಲಿ ಉದಯಿಸಿದನು.  
(ಇಲ್ಲಿ ಸೂರ್ಯ-+ನ್+ಉ=ಸೂರ್ಯನು)  
2. ಎಮ್ಮೆಯು ಹಾಲನ್ನು ಕೊಡುತ್ತದೆ.  

□ ಹಲವು ಸಂದರ್ಭಗಳಲ್ಲಿ ಪ್ರಥಮಾ ವಿಭಕ್ತಿಯ ಏಕವಚನ ರೂಪವನ್ನು ನಾಮಪ್ರಕೃತಿ ರೂಪದಲ್ಲೇ ಹೇಳುವುದು ವಾಡಿಕೆ. ಅಂದರೆ ನಾಮಪ್ರಕೃತಿಯ ರೂಪವೇ ಪ್ರಥಮಾ ವಿಭಕ್ತಿಯ ರೂಪವಾಗಿರುವುದು.  

ಉದಾ:  
1. ಚಂದ್ರ ಆಕಾಶದಲ್ಲಿ ಹೊಳೆಯುತ್ತಾನೆ.  
2. ಗಂಧಕ ನೀರಲ್ಲಿ ಕರಗುವುದಿಲ್ಲ.  

(೨) ದ್ವಿತೀಯಾ ವಿಭಕ್ತಿ: ದ್ವಿತೀಯಾ ವಿಭಕ್ತಿ ಪ್ರತ್ಯಯ “ಅನ್ನು” ಆಗಿದೆ.  
ಈ ವಿಭಕ್ತಿ ಪ್ರತ್ಯಯವು ಸಾಮಾನ್ಯವಾಗಿ ಕರ್ಮಪದದ ಮೇಲೆ ಬರುವುದು.
