ಬ್ರಹ್ಮಸೂತ್ರ : ಸಂಧಿಕಾರ್ಯ ನಡೆಯುವಾಗ ಅ, ಆ ಕಾರೆಗಳಲ್ಲಿ ಯಾವುದಾದರೊಂದು ಸ್ವರಕ್ಕೆ ನ, ಐ ಕಾರೆಗಳು ಪರವಾದರೆ ಐ ಕಾರವೂ ಓ, ಔ ಕಾರಗಳು ಪರವಾದರೆ ಔಕಾರವೂ ಆದೇಶಗಳಾಗಿ ಬರುವುದಾದರೆ ಅದು ವೃದಿಸಂಧಿಯೆನಿಸುವುದು.  

[೪] ಯೆಣ್‌ ಸಂಧಿ :  
ಇತ್ಯಾದಿ, ಗುರ್ವಾಜ್ಞೆ, ನಿತ್ರಾರ್ಜಿತ - ಈ ಶಬ್ದಗಳನ್ನು ಬಿಡಿಸಿ ನೋಡೋಣ...  

[i] ಇತ್ಯಾದಿ = ಇತಿ + ಆದಿ  
= ಇ + [ತ್ + ಆ + ದಿ] + ಆ  
ಸ ಇಕಾರಕ್ಕೆ ಯೆತ್‌ಕಾರಾದೇಶನಾಗಲು  
= ಇ + (ತ್ + ಆ + ದಿ) + ಆ  
= ಇತ್ಯಾದಿ.... [∵ ತ್ + ಆ + ದಿ = ತ್ಯಾದಿ]  

[ii] ಗುರ್ವಾಜ್ಞೆ = ಗುರ್ + ವಾಜ್ಞೆ  
= ಗು + [ವ್ + ಆ + ಜ್ಞೆ] + ಆ  
= ಗುರ್ವಾಜ್ಞೆ.... [∵ ವ್ + ಆ + ಜ್ಞೆ = ವಾಜ್ಞೆ]  

[iii] ನಿತ್ರಾರ್ಜಿತ = ಪಿತೃ + ಆರ್ಜಿತ  
= ಪಿ + [ತ್ + ಖು + ಆ] + ರ್ಜಿತ  
= ಪಿ + (ತ್ + ಖು + ಆ) + ರ್ಜಿತ  
= ನಿತ್ರಾರ್ಜಿತ.... (∵ ತ್ + ಖು + ಆ = ತ್ರಾ)  

ಮೇಲಿನ ಉದಾಹರಣೆಗಳಲ್ಲಿ ಪೂರ್ವಾರ್ಥದಲ್ಲಿರುವ ಸ್ವರಾಕ್ಷರಗಳಾದ ಇ, ಉ, ಖು ಕಾರಗಳಿಗೆ ಕ್ರಮವಾಗಿ ಯ್‌, ವನ್ಸ್‌, ರ್‌ಗಳು ಆದೇಶವಾಗಿ ಬಂದಿರುವುದನ್ನು ನೋಡಬಹುದು ; ಇಲ್ಲಿ ಸವರ್ಣ ಸ್ವರ ಪರವಾಗಿ ಬಂದಿಲ್ಲದಿರುವುದು ಗಮನಾರ್ಹ ಅಂಶ. ಈ ಕೆರ್ನಾದ ಸಂಧಿಯು 'ಯಣ್‌ ಸಂಧಿ' ಎಂದು ಬಿಂದುಸುವುದು.
