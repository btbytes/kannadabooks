(೨) ಪ್ರಾಸ: ಯಾವುದೇ ಪದ್ಯದ ಪ್ರತಿಯೊಂದು ಪಾದದ  
ಮೊದಲನೆಯ ಮತ್ತು ಎರಡನೆಯ ಸ್ವರಗಳ ನಡುವೆ. ಒಂದೇ ಜಾತಿಯ  
ವ್ಯಂಜನಾಕ್ಷರ ಬರುವುದನ್ನು “ಪ್ರಾಸ” ಎನ್ನುತ್ತೇವೆ. ಮೊದಲನೆಯ ಪಾದದ  
ಪ್ರಾಸಾಕ್ಷರದ ಹಿಂದಿನ ಅಕ್ಷರ ಪ್ರಸ್ತಸ್ವರವಾಗಿರಲೀ, ದೀರ್ಘಸ್ವರವಾಗಿರಲೀ,  
ಅನುಸ್ವಾರವಾಗಿರಲೀ ವಿಸರ್ಗವಾಗಿರಲೀ ಆಗಿದ್ದ ಪಕ್ಷದಲ್ಲಿ ಉಳಿದೆಲ್ಲ ಪಾದ  
ಗಳಲ್ಲಿಯೂ ಅದೇ ಲಕ್ಷಣ ಕಂಡುಬರುವುದು. ಇದು ಪ್ರಾಸ ನಿಯಮ.  
ಉದಾ:  

ಮಡದಿ ನಿಜ ನಿಳಯನು ಬಿಟ್ಟಡಿ  

ಗಡಿಗೆ ಪರಗೃಹೆದೊಳಗೆ ಬಾಯನು ;  

ಬಡಿದು ಮನೆಮುಕೆನಾರ್ತೆಯೆನ್ನದೆ ಬೀದಿಗಲಹವನು |  

ಒಡರಿಚುವ ಸತಿಯೊಬ್ಬನುಂಬೆಂ  

ದೆಡಹಿ ಕಾಣದ ದಿಟ್ಟೆ ಹತ್ತನು |  

ಹಡೆದೊಡೆಯು ವರ್ಜಿಸುವುದುತ್ತಮ ಪುರುಷರುಗಳೆಂದ  

—ಕರ್ಣಾಟಿ ಭಾರತ ಕಥಾಮಂಜರಿ: ಉಡ್ಕ್ಯೋಗಪರ್ನ  

ಮಡ = ಮ್ + ಅ + ಡ್ + ಅ; ಒಡ = ಒ + ಡ್ + ಅ  

ಗಡಿ = ಗ್ + ಅ + ಡ್ + ಇ; ದೆಡ = ದ್ + ಎ + ಡ್ + ಅ  

ಬಡಿ = ಬ್ + ಅಡ್ + ಇ; ಹಡೆ = ಹ್ + ಅಡ್  

ವಿ.ಸೂ. : “ರಗಳೆ”ಗಳಲ್ಲಿ ಪಾದಾಂತ್ಯ (ಸಾಲಿನ ಕೊನೆ) ದಲ್ಲೂ  
ಪ್ರಾಸ ನಿಯಮ ಕಂಡುಬರುವುದು ; ಇದೊಂದು ವಿಶಿಷ್ಟ ಲಕ್ಷಣವೇ ಸರಿ.  

(ಓ) ಗಣ: ಪದ್ಯದ ಪ್ರತಿಪಾಡದಲ್ಲಿರುವ ಅಕ್ಷರಗಳ ಗುಂಪಿಗೆ  
“ಗಣ” ಎಂದು ಹೆಸರು. ಗಣಗಳಲ್ಲಿ ಪ್ರಧಾನವಾಗಿ ಮಾತ್ರಾ ಗಣಗಳು ಮತ್ತು  
ಅಕ್ಷರ ಗಣಗಳು ಎಂದು ಎರಡು ವಿಧ.
