ವ್ಯಾಖ್ಯೆ : ಉತ್ತರಪದದ ಅರ್ಥವೇ ಪ್ರಧಾನವಾಗಿದ್ದು, ಪೂರ್ವ  
ಹಾಗೂ ಉತ್ತರಪದಗಳು ಲಿಂಗ ವಚನ ವಿಭಕ್ತಿಗಳಿಂದ ಸಮಾನವಾಗಿದ್ದು,  
ಅವೆರಡೂ ಪದಗಳು ವಿಶೇಷಣ ವಿಶೇಷ್ಯ ಸಂಬಂಧದಿಂದ ಕೂಡಿ ಆಗುವ  
ಸಮಾಸಕ್ಕೆ ಕರ್ಮಧಾರಯ ಸಮಾಸ ಎಂದು ಹೆಸರು.  
ಉದಾ :  
- ಹಿರಿದು + ಬಾಗಿಲು = ಹೆಬ್ಬಾಗಿಲು [ವಿ.ಪೂ.ಕ]  
- ಹಿರಿದು + ಜೇನು = ಹೆಜ್ಜೇನು [ವಿ.ಪೂ.ಕ]  
- ತಣ್ಣನೆ + ಗಾಳಿ = ತಂಗಾಳಿ [ವಿ.ಪೂ.ಕ]  
- ಸಿಹಿಯಾದ + ನೀರು = ಸಿಹಿನೀರು [ವಿ.ಪೂ.ಕ]  
- ಹಣ್ಣಾದ + ಎಲೆ = ಹಣ್ಣೆಲೆ [ವಿ.ಪೂ.ಕ]  
- ಎಳದು + ಕರು = ಎಳಗರು [ವಿ.ಪೂ.ಕ]  
- ಕಿರಿದು + ದಾರಿ = ಕಿರುದಾರಿ [ವಿ.ಪೂ.ಕ]  
- ಮೆಲ್ಲಿತು + ನುಡಿ = ಮೆಲ್ನುಡಿ [ವಿ.ಪೂ.ಕ]  
- ಕೆಚ್ಚನೆ + ಚೇಳು = ಕೆಂಚೇಳು [ವಿ.ಪೂ.ಕ]  
- ಇನಿದು + ಸರ = ಇಂಚರ [ವಿ.ಪೂ.ಕ]  
- ನೀಲವಾದ + ಆಕಾಶ = ನೀಲಾಕಾಶ [ವಿ.ಪೂ.ಕ]  
- ಶ್ವೇತವಾದ + ಅಂಬರ = ಶ್ವೇತಾಂಬರ [ವಿ.ಪೂ.ಕ]  

[ಸೂಚನೆ : ಈ ಸಮಾಸಗಳಲ್ಲಿ ಪೂರ್ವಪದಗಳು ವಿಶೇಷಣಗಳಾಗಿಯೂ  
ಉತ್ತರಪದಗಳು ವಿಶೇಷ್ಯಗಳಾಗಿಯೂ ಇರುವುದರಿಂದ, ಇವುಗಳಿಗೆ ವಿಶೇಷಣ  
ಪೂರ್ವಪದ ಕರ್ಮಧಾರಯ ಸಮಾಸ [ವಿ.ಪೂ.ಕ] ವೆಂದು ಹೇಳುವುದು  
ವಾಡಿಕೆ.]  

(೩) ದ್ವಿಗು ಸಮಾಸ :  
- ಮೂರು [ಪೂ.ಪ] + ಲೋಕ [ಉ.ಪ] = ಮೂಲೋಕ  
ಇಲ್ಲಿ “ಮೂರು” ಎಂಬ ಸಂಖ್ಯಾವಾಚಕವು “ಲೋಕ” ಎಂಬ ನಾಮಪದ  
ದೊಂದಿಗೆ ಸೇರಿ ಸಮಸ್ತಪದವಾಗಿರುವುದು - ಇದು ದ್ವಿಗು ಸಮಾಸ  
ಎನಿಸುವುದು.
