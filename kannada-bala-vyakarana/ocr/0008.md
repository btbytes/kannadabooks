(3) ಎರಡು ಪದಗಳುಳ್ಳಿ ಐದು ವಾಕ್ಯಗಳನ್ನು ಜ್ಞಾಪಿಸಿರಿ.  
ಹೂವು ಅರಿತು; ...  
ಉದಾಹರಣೆ : ಬಿಕ್ಕು ಹಾಲು ಫುಡಿಯಿತು. ...  

(4) ಈ ಸದಗಳುಳ್ಳ ಐದು ವಾಕ್ಯಗಳನ್ನು ಬರೆಯಿರಿ.  

(5) ನಾಲ್ಕು ಪದಗಳುಳ್ಳ ಮೂರು ವಾಕ್ಯಗಳನ್ನು ಬರೆಯಿರಿ.  

(6) ಈ ಪದಗಳನ್ನು ಸ್ಪಷ್ಟವಾಗಿ ಉಚ್ಛರಿಸಿರಿ : ಹೆಕ್ಕಿ, ಅಕ್ಕಿ,  
ಅನ್ನ, ಅಣ್ಣ, ಉಪ್ಪ, ತೀಕ್ಷ್ಣ, ಗಾನಜ್ಞಾನ, ರಾಷ್ಟ್ರ, ಆಜ್ಞೆ, ನಕ್ಷತ್ರ,  
ಉತ್ಪಾನ, ಉತ್ಸವ, ಸಂಸ್ಕೃತ, ಅಷ್ಟಾವಕ್ರ.  

(7) ದಿಹಳೆ, ರಸಳ್ಕ, ನಿಜರ, ಜನನ, ವತಾಕ್ಕೆ, ಮರಿಪಳ್ಕೆ, ನಿವಾಶರೆ,  
ಪಾಜಾತರಿ, ಯೆಲನಾಶಿ, ಮಣಕಿಕನೆಂಟಿ - ಈ ಪದಗಳಲ್ಲಿ ಅಕ್ಷರಗಳು  
ಕಲಸಿಹೋಗಿವೆ ; ಅರ್ಥವತ್ತಾದ ಸದಗಳಾಗುವಂತೆ ಅಕ್ಷರಗಳನ್ನು ಕ್ರಮವಾಗಿ  
ಜೋಡಿಸಿ ಬರೆಯಿರಿ.  

(8) ಅ-ಪಟ್ಟಿಯಲ್ಲಿರುವ ಸದಗಳೊಂದಿಗೆ ಬ-ಪಟ್ಟಿಯಲ್ಲಿರುವ  
ಸದಗಳನ್ನು ಕೂಡಿಸಿ ಅರ್ಥಪೂರ್ಣವಾದ ವಾಕ್ಯಗಳನ್ನು ಬರೆಯಿರಿ.  

| ಅ-ಪಟ್ಟಿ | ಬ-ಪಟ್ಟಿ |
| --- | --- |
| ಕೋಳಿ | ಜೊಗಳಿತು |
| ಕತ್ತೆ | ಘರ್ಜಿಸಿತು |
| ನಾಯಿ | ಅರಚಿತು |
| ಕುದುರೆ | ಕೂಗಿತು |
| ಸಿಂಹ | ಕೆನೆಯಿತು |

(9) ಕೆಳಗೆ ಕೊಟ್ಟಿರುವ ವಾಕ್ಯಗಳಲ್ಲಿ ಪದಗಳು ಸ್ಥಾನೆಪಲ್ಲಟಿಗೊಂಡಿವೆ.  
ಅವುಗಳನ್ನು ಕ್ರಮವಾಗಿ ಜೋಡಿಸಿ ಬರೆಯಿರಿ.  

(೧) ಜೋಳದ ಆಹಾರೆ ರುಚಿಯಾದ ರೊಟ್ಟಿ.  
(೨) ಅತ್ಯುತ್ತಮವಾದ ಮಗುನಿಗೆ ತಾಯಿಯ ಹಾಲು ಆಹಾರೆ.  
(ಬಹುಶಯನಾಗಿ ಕರ್ನಾಟಕದಲ್ಲಿರುವ ಕನ್ನಡನನ್ನು ಕನ್ನಡೇತರರು)
