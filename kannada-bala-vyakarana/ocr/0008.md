(3) ಎರಡು ಪದಗಳುಳ್ಳ  ಐದು ವಾಕ್ಯಗಳನ್ನು ಜ್ಞಾಪಿಸಿರಿ.  
ಉದಾ: ಹೂವು ಅರಳಿತು... 

(4) ಮೂರು ಪದಗಳುಳ್ಳ ಐದು ವಾಕ್ಯಗಳನ್ನು ಬರೆಯಿರಿ. 

ಉದಾ: ಬೆಕ್ಕು ಹಾಲು ಕುಡಿಯಿತು...   

(5) ನಾಲ್ಕು ಪದಗಳುಳ್ಳ ಮೂರು ವಾಕ್ಯಗಳನ್ನು ಬರೆಯಿರಿ.  

(6) ಈ ಪದಗಳನ್ನು ಸ್ಪಷ್ಟವಾಗಿ ಉಚ್ಛರಿಸಿರಿ : ಹೆಕ್ಕಿ, ಅಕ್ಕಿ,  
ಅನ್ನ, ಅಣ್ಣ, ಉಷ್ಣ, ತೀಕ್ಷ್ಣ, ಗಾನ, ಜ್ಞಾನ, ರಾಷ್ಟ್ರ, ಆಜ್ಞೆ, ನಕ್ಷತ್ರ,  
ಉತ್ಥಾನ, ಉತ್ಸವ, ಸಂಸ್ಕೃತ, ಅಷ್ಟಾವಕ್ರ.  

(7) ದಿಹಳ, ರಸಳ, ನಿಜರ, ಜನನ, ವತಾರೆ, ಮರಿಪಳ, ನಿವಾಶರ,  
ಪಾಜಾತರಿ, ಯಲವಾಶಿ, ಮಣರಕವೆಂಟ  - ಈ ಪದಗಳಲ್ಲಿ ಅಕ್ಷರಗಳು  
ಕಲಸಿಹೋಗಿವೆ ; ಅರ್ಥವತ್ತಾದ ಪದಗಳಾಗುವಂತೆ ಅಕ್ಷರಗಳನ್ನು ಕ್ರಮವಾಗಿ  
ಜೋಡಿಸಿ ಬರೆಯಿರಿ.  

(8) ಅ-ಪಟ್ಟಿಯಲ್ಲಿರುವ ಸದಗಳೊಂದಿಗೆ ಬ-ಪಟ್ಟಿಯಲ್ಲಿರುವ  
ಸದಗಳನ್ನು ಕೂಡಿಸಿ ಅರ್ಥಪೂರ್ಣವಾದ ವಾಕ್ಯಗಳನ್ನು ಬರೆಯಿರಿ.  

| ಅ-ಪಟ್ಟಿ | ಬ-ಪಟ್ಟಿ |
| --- | --- |
| ಕೋಳಿ | ಜೊಗಳಿತು |
| ಕತ್ತೆ | ಘರ್ಜಿಸಿತು |
| ನಾಯಿ | ಅರಚಿತು |
| ಕುದುರೆ | ಕೂಗಿತು |
| ಸಿಂಹ | ಕೆನೆಯಿತು |

(9) ಕೆಳಗೆ ಕೊಟ್ಟಿರುವ ವಾಕ್ಯಗಳಲ್ಲಿ ಪದಗಳು ಸ್ಥಾನೆಪಲ್ಲಟಗೊಂಡಿವೆ.  
ಅವುಗಳನ್ನು ಕ್ರಮವಾಗಿ ಜೋಡಿಸಿ ಬರೆಯಿರಿ.  

(೧) ಜೋಳದ ಆಹಾರ ರುಚಿಯಾದ ರೊಟ್ಟಿ.  
(೨) ಅತ್ಯುತ್ತಮವಾದ ಮಗುವಿಗೆ ತಾಯಿಯ ಹಾಲು ಆಹಾರೆ.
(3) ಕಡ್ಡಾಯವಾಗಿ ಕರ್ನಾಟಕದಲ್ಲಿರುವ ಕನ್ನಡವನ್ನು ಕನ್ನಡೇತರರು ಕಲಿಯಬೇಕು.
