□ ವರ್ಗೀಯ ವ್ಯಂಜನಗಳನ್ನು ಉಚ್ಚಾರದ ಆಧಾರದ ಮೇಲೆ  
ಅಲ್ಪಪ್ರಾಣ, ಮಹಾಪ್ರಾಣ, ಅನುನಾಸಿಕ ಎಂಬುದಾಗಿ ಮೂರು ಬಗೆಯಾಗಿ  
ವಿಂಗಡಿಸಬಹುದು.

(೧) “ಕಚಟ ತಪ” ಮತ್ತು “ಗಜಡ ದಬ” ಇವು ತೇಲಿಸಿ-ಉಚ್ಚರಿಸ  
ಸುವ ವ್ಯಂಜನಗಳು ; ಇವುಗಳಿಗೆ “ಅಲ್ಪಪ್ರಾಣ” ಗಳೆಂದು ಹೆಸರು.

(೨) “ಖಛಠ ಥಫ” ಮತ್ತು “ಘ ಝ ಢ ಧ ಭ” - ಇವು ಹೆಚ್ಚು  
ಒತ್ತು ಕೊಟ್ಟು ಉಚ್ಚರಿಸುವ ವ್ಯಂಜನಗಳು ; ಇವುಗಳಿಗೆ “ಮಹಾಪ್ರಾಣ”  
ಗಳೆಂದು ಹೆಸರು.

(೩) ಙ ಞ ಣ ನ ಮ - ಇವು ಮೂಗಿನ ಸಹಾಯದಿಂದ ಉಚ್ಚರಿಸ  
ಸುವ ವ್ಯಂಜನಗಳು ; ಇವುಗಳಿಗೆ “ಅನುನಾಸಿಕ” ಗಳೆಂದು ಹೆಸರು.

□ ಅವರ್ಗೀಯ ವ್ಯಂಜನಗಳು : ಯ, ರ, ಲ, ವ, ಶ, ಷ,  
ಸ, ಹ, ಳ - ಇವು ಅವರ್ಗೀಯ ವ್ಯಂಜನಗಳು ; ಯ-ಕಾರದಿಂದ ಳ-ಕಾರದ  
ವರೆಗಿನ ಈ ವ್ಯಂಜನಗಳ ಒಟ್ಟು ಸಂಖ್ಯೆ ಒಂಭತ್ತು.

ಯೋಗವಾಹಗಳು :

ಸ್ವರಾಕ್ಷರದ ಬಲಬದಿಯಲ್ಲಿ ಒಂದು ಸೊನ್ನೆ ಬಂದರೆ “ಅನುಸ್ವಾರ”  
ವೆನಿಸುವುದು ; ಮತ್ತು ಒಂದರ ಮೇಲೊಂದರಂತೆ ಎರಡು ಸೊನ್ನೆಗಳು ಬಂದರೆ  
“ವಿಸರ್ಗ”ವೆನಿಸುವುದು. ಈ ಎರಡು ಪ್ರಭೇದಗಳನ್ನು ಯೋಗವಾಹಗಳೆನ್ನುವರು.

ಅನುಸ್ವಾರ (ಂ) ; ವಿಸರ್ಗ (ಃ)

ಉದಾಹರಣೆಗಳು : ಅಂ ; - ಅಃ |

ಯೋಗವಾಹಗಳನ್ನು ಸ್ವರಗಳ ಸಹಯೋಗದೊಂದಿಗೆ ಮಾತ್ರ ಉಚ್ಚರಿಸ  
ಬಹುದಾದ ಕಾರಣ ಅವುಗಳಿಗೆ ಆ ಹೆಸರು ಬಂದಿದೆ.

ಗುಣಿತಾಕ್ಷರಗಳು :

ಮೂಲ ವ್ಯಂಜನಗಳು ಅರ್ಧಾಕ್ಷರಗಳು. ಇವುಗಳ ಉಚ್ಚಾರ ಕಠಿಣ  
ಹಾಗೂ ಅಸ್ಪಷ್ಟ. ಈ ಅಪೂರ್ಣ ಅಕ್ಷರಗಳೊಂದಿಗೆ ಸ್ವರಗಳು ಸೇರಿದಾಗ ಸ್ಪಷ್ಟ  
ವಾಗಿ ಉಚ್ಚರಿಸಬಹುದಾದ ಹೊಸ ಅಕ್ಷರಗಳು ಲಭಿಸುತ್ತವೆ... ಹೀಗೆ ರೂಪ  
ತಳೆಯುವ ವ್ಯಂಜನಗಳಿಗೆ “ಗುಣಿತಾಕ್ಷರ” ಗಳೆಂದು ಹೆಸರು.
