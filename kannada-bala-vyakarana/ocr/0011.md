□ ವರ್ಗೀಯ ವ್ಯಂಜನಗಳನ್ನು ಉಚ್ಛಾರೆದೆ ಆಧಾರದ ಮೇಲೆ  
ಅಲ್ಪಪ್ರಾಣ, ಮಹಾಪ್ರಾಣ, ಅನುನಾಸಿಕ ಎಂಬುದಾಗಿ ಮೂರು ಜಾಗೆಯಾಗಿ  
ವಿಂಗಡಿಸಬಹುದು.

(೧) “ಕಚಟ ತಪ ಮತ್ತು “ಗಜಡಭ” ಇವು ತೇಲಿಸಿ-ಉಚ್ಛರಿಸಿ  
ಸುವ ವ್ಯಂಜನಗಳು ; ಇವುಗಳಿಗೆ “ಅಲ್ಪಪ್ರಾಣ” ಗಳೆಂದು ಹೆಸರು.

(೨) “ಖಛಭಠ ಥಪ” ಮತ್ತು “ಫ ಘ ರ ಢ ಧ ಭ” - ಇವು ಹೆಚ್ಚು  
ಒತ್ತು ಕೊಟ್ಟಿ ಉಚ್ಛರಿಸಿವುವ ವ್ಯಂಜನಗಳು ; ಇವುಗಳಿಗೆ “ಮಹಾಪ್ರಾಣ”  
ಗಳೆಂದು ಹೆಸರು.

(೩) ಜಳ ಣ ನ ಮ - ಇವು ಮೂಗಿನ ಸಹಾಯದಿಂದ ಉಚ್ಛರಿಸಿ  
ಸುವ ವ್ಯಂಜನಗಳು ; ಇವುಗಳಿಗೆ “ಅನುನಾಸಿಕ” ಗಳೆಂದು ಹೆಸರು.

□ ಅವರ್ಗೀಯ ವ್ಯಂಜನಗಳು : ಯ, ರ, ಲ, ವ, ಶ, ಷ,  
ಸ, ಹ, ಳ - ಇವು ಅವರ್ಗೀಯ ವ್ಯಂಜನಗಳು ; ಯ-ಕಾರದಿಂದ ಳ-ಕಾರದ  
ವರೆಗಿನ ಈ ವ್ಯಂಜನಗಳ ಒಟ್ಟೊ ಸಂಖ್ಯೆ ಒಂಭತ್ತು.

ಯೋಗವಾಹಗಳು :

ಸ್ವರಾಕ್ಷರದ ಬಲಬದಿಯಲ್ಲಿ ಒಂದು ಸೊನ್ನೆ ಬಂದರೆ “ಅನುಸ್ವಾರ”  
ವೆನಿಸುವುದು ; ಮ್ತು ಒಂದರ ಮೇಲೊಂದರಂತೆ ಎರಡರ ಸೊನ್ನೆ ಗಳು ಬಂದರೆ  
“ವಿಸರ್ಗ”ವೆನಿಸುವುದು. ಈ ಎರಡು ಪ್ರಜ್ಛೇದಗಳನ್ನು ಯೋಗವಾಹೆಗಳೆನ್ನುವರು.

ಅನುಸ್ವಾರ (೦) ; ವಿಸರ್ಗ (೪)

ಉದಾಹರಣೆಗಳು : ಅಂ ; - ಅಃ |

ಯೋಗವಾಹಗಳನ್ನು ಸ್ವರಗಳ ಸಹಯೋಗದೊಂದಿಗೆ ಮಾತ್ರ ಉಚ್ಛರಿಸಿ  
ಬಹುದಾದ ಕಾರಣ ಅವುಗಳಿಗೆ ಆ ಹೆಸರು ಬಂದಿದೆ.

ಗುಣಿತಾಕ್ಷರಗಳು :

ಮೂಲ ವ್ಯಂಜನಗಳು ಅರ್ಧಾಕ್ಷರಗಳು. ಇವುಗಳ ಉಚ್ಛಾರೆ ಕಠಿಣ  
ಹಾಗೂ ಅಸ್ಪಷ್ಟ. ಈ ಅಪೊರ್ಣ ಅಕ್ಷರಗಳೊಂದಿಗೆ ಸ್ವರಗು ಸೇರಿದಾಗ ಸ್ಪಷ್ಟ  
ವಾಗಿ ಉಚ್ಛರಿಸಬಹುದಾದ ಹೊಸ ಅಕ್ಷರಗಳು ಲಭಿಸುತ್ತವೆ... ಹೀಗೆ ರೂಪ  
ತಳೆಯುವ ವ್ಯಂಜನಗಳಿಗೆ “ಗುಣಿತಾಕ್ಷರ” ಗಳೆಂದು ಹೆಸರು.
