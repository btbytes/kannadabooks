ನ್ಯಾಖ್ಯೆ : ಪೂರ್ವಪದವು ಸಂಖ್ಯಾ ವಾಚಕವೂ ಉತ್ತರಸದವ್ರ  
ನಾಮಪದವೂ ಆಗಿರುವಾಗ, ಪೂರ್ವಪದವು ಉತ್ತರಪದದೊಂದಿಗೆ ಸೇರಿ  
ಆಗುವ ಸಮಾಸಕ್ಕೆ ದ್ವಿಗು ಸಮಾಸವೆಂದು ಹೆಸರು.  
ಉದಾ : ನಾಲ್ಕು + ಮಡಿ = ನಾಲ್ವಡಿ [ದ್ವಿ.ಸ.]  
ಎಂಟು + ದೆಸೆ = ಎಣ್ಣೆಸೆ [ದ್ವಿ.ಸ.]  
ಎರಡು + ಕೆಲ = ಇರ್ಕೆಲ [ದ್ವಿ.ಸ.]  
ಒಂದು + ಕಟ್ಟು = ಒಗ್ಗಟ್ಟು [ದ್ವಿ.ಸ.]  
ಒಂದು + ಕಣ್ಣು = ಒಕ್ಕಣ್ಣು [ದ್ವಿ.ಸ.]  

(೪) ಅಂಶಿ ಸಮಾಸ :  
“ತುದಿಮೂಗು” ಎಂಬ ಸಮಸ್ತ ಪದನನ್ನು ವಿಗ್ರಹೆ. ವಾಕ್ಯ ಮಾಡಿ  
ನೋಡೋಣ. ಮೂಗಿನ + ತುದಿ = ತುದಿಮೂಗು  
ಇಲ್ಲಿ ಪ್ರಧಾನವಾಗಿರುವುದು ಮೂಗಿನ ತುದಿಯೇ ಹೊರತು ಮೂಗಲ್ಲ  
“ತುದಿ” ಎಂಬುದು ಮೂಗಿನ ಒಂದು ಆಂಶ -ಮಾತ್ರ. ಇಲ್ಲಿ ಮೂಗು  
ಅಂಶಿಯಾಗಿರುವುದು-  
- ಬ ಖಿ ಪ್ರ ವ  
ವಿಗ್ರಹ ವಾಕ್ಯದಲ್ಲ ಮೂಗಿನ” ಎಂಬ ಪದ ಪೂರ್ವಪದನಾಗಿದ್ದರೂ,  
ಪೂರ್ವಪದ ಮತ್ತು ಉತ್ತರಪದಗಳು ಸೇರಿ ಸಮಾಸಾದಾಗ ಸಮಸ್ತ ಪದದಲ್ಲಿ  
ಪೂರ್ವ ಮತ್ತು ಉತ್ತರಪದಗಳು ಆದಲು ಬದಲಾಗಿರುವುದನ್ನು ಕಾಣುತ್ತೇನೆ.  
ಆದುದರಿಂದ ಸಮಸ್ತಪದದಲ್ಲಿನ ಪೂರ್ವಪದವು ಪ್ರಧಾನವಾಗುವುದು. ಹೀಗೆ  
ಪೂರ್ವಸದದ ಅರ್ಥ ಪ್ರಧಾನವಾಗಿ ಉಳ್ಳ ಸಮಾಸಕ್ಕೆ ಅಂಶಿಸಮಾಸವೆಂದು  
ಹೆಸರು.  
ನ್ಯಾಖ್ಯೆ : ಪೂರ್ವ ಮತ್ತು ಉತ್ತರಪದಗಳು ಅಂಶಾಂಶಿಭಾವ  
ಸಂಬಂಧದಿಂದ ಸೇರಿ ಸಮಾಸವಾದಾಗ, ಪೂರ್ವಪದದ ಅರ್ಥವು ಪ್ರಧಾನ  
ವಾಗಿದ್ದರೂ ಅದು ಅಂಶಿ ಸಮಾಸವೆನಿಸುವುದು.  
ಅಂಶ--ಪೂರ್ಣದ ಒಂದು ಭಾಗ ; ಅಂಶಿ-ಅಂಶಗಳನ್ನು ಬಳಗೊಂಡಿರುವುದು.  
ಅಂಶಾಂಶಿಭಾವ--ಆಂಶಕ್ಕೂ ಅಂಶಿಗೂ ಇರುವ ಸಂಬಂಧ.
