ಸಿದ್ಧಿಸುವುವು ; ಇವು ಲಿಂಗ ವಚನ, ವಿಭಕ್ತಿಗಳಿಂದ ವ್ಯತ್ಯಾಸವಾಗದ ರೂಪಗಳು.  
ಉದಾಹರಣೆ :  

೧. ಬೆಳಕು ಬರಲು ಕತ್ತಲೆ ಸರಿಯಿತು. (ಬರಲು = ಬರು + ಅಲು)  
೨. ಈ ಹಣ್ಣು ತಿನ್ನಲಿಕ್ಕೆ ರುಚಿಯಾಗಿದೆ. (ತಿನ್ನಲಿಕ್ಕೆ = ತಿನ್ನು + ಅಲಿಕ್ಕೆ)  
೩. ನೀನು ರೊಟ್ಟಿ ತಿಂದು ಹೋಗು. (ತಿಂದು = ತಿನ್ನು + ದು)  
೪. ಮಾಡಿ ನೋಡು ಮದ್ದಿನ ಗುಣ. (ಮಾಡಿ = ಮಾಡು + ಇ)  
೫. ಊರಿಗೆ ಹೋದರೆ ಹಿಂದಿರುಗಲಾರೆ. (ಹೋದರೆ = ಹೋಗು + ದರೆ)  
೬. ಅವಳು ನಗುತ್ತೆ ಮನೆಗೆ ಹೋದಳು. (ನಗುತ್ತೆ = ನಗು + ಉತ್ತೆ)  
೭. ನಾನು ನಿನ್ನನ್ನು ನೋಡದೆ ಇರಲಾರೆ. (ನೋಡದೆ = ನೋಡು + ಅದೆ)  
೮. ಕಮಲೆಯು ನನ್ನನ್ನು ಬರೆ ಹೇಳಿದ್ದಾಳೆ. (ಬರೆ = ಬರು + ಅ)  
೯. ಕಿಂದರಿ ಜೋಗಿ ಹಾಡುತೆ ಬರುತಿಹನು. (ಹಾಡುತೆ = ಹಾಡು + ಉತ್ತೆ)  
೧೦. ರಾಷ್ಟ್ರಾಧ್ಯಕ್ಷರು ಬರುತ್ತಿರಲು ಮಕ್ಕಳು ಚಪ್ಪಾಳೆ ತಟ್ಟಿದರು.  
(ಬರುತ್ತಿರಲು = ಬರು + ಉತ್ತೆ + ಅರಲು)  

ನೆನಪಿಡಿ : ಕೃದಂತಾವ್ಯಯಗಳು ಪೂರ್ಣ ಕ್ರಿಯಾರ್ಥವನ್ನು ಕೊಡುವುದಿಲ್ಲವಾದ ಕಾರಣ ಮತ್ತೊಂದು ಕ್ರಿಯೆಯನ್ನು ಅಪೇಕ್ಷಿಸುವುದು. ಇವುಗಳ ಲಕ್ಷಣ, ಉದಾ: ನಗುತ್ತ ಇದ್ದನು; ನೋಡದೆ ಇರಲಾರೆ; ಮಾಡಿ ನೋಡು.  

ಅಭ್ಯಾಸ ಪತ್ರಿಕೆ ೧೪  
1. “ಬರೆಯುವನು” ಈ ಕ್ರಿಯಾಪದದಲ್ಲಿ ಸೇರಿರುವ ಕಾಲಸೂಚಕ ಪ್ರತ್ಯಯ ಯಾವುದು? ಮತ್ತು ಆಖ್ಯಾತ ಪ್ರತ್ಯಯ ಯಾವುದು?  
2. ಸ್ತ್ರೀಲಿಂಗ ಏಕವಚನದಲ್ಲಿ “ಕೊಡು” ಧಾತುವಿನ ಭವಿಷ್ಯಕಾಲದ ಕ್ರಿಯಾಪದ ರೂಪವನ್ನು ಬರೆಯಿರಿ.  
3. “ಹೋದನು” ಈ ಕ್ರಿಯಾಪದವನ್ನು ಬಿಡಿಸಿ ಬರೆಯಿರಿ.  
4. “ಕಾಣುವ” ಈ ಶಬ್ದದಲ್ಲಿ ಸೇರಿರುವ ಪ್ರತ್ಯಯಗಳು ಯಾವುವು? ಅವುಗಳ ವಿಶೇಷವೇನು?  
5. ಕೃದಂತ ನಾಮ ಎಂದರೇನು? ಉದಾಹರಣೆಗಳ ಸಹಿತ ತಿಳಿಸಿ.
