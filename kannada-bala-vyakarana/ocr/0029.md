ಗಿರಿ + ಇಂದ್ರ = ಗಿರೀಂದ್ರ .....(ಅ + ಈ = ಎ)  
ಧ್ವಜ + ಆರೋಹಣ = ಧ್ವಜಾರೋಹಣ .....(ಅ + ಆ = ಎ)  
ಲಕ್ಷ್ಮೀ + ಈಶ = ಲಕ್ಷ್ಮೀಶ .....(ಈ + ಈ = ಏ)  

(೨) ಗುಣ ಸಂಧಿ :  
“ಗಣೇಶ” ಈ ಶಬ್ದವನ್ನು ಬಿಡಿಸಿ ನೋಡೋಣ.  
ಗಣೇಶ = ಗಣ + ಈಶ  
= ಗ + ಣ್‌ + (ಅ + ಈ) + ಶ  
ಇಲ್ಲಿ ಅ ಕಾರಕ್ಕೆ ಈ ಕಾರ ಪರವಾಗಿದೆ.  
= ಗ + ಣ್‌ + (ಏ) + ಶ  
ಇಲ್ಲಿ ಅ, ಈ ಗಳ ಸ್ಥಾನದಲ್ಲಿ ಏ ಕಾರೆ ಆದೇಶವಾಗಿ ಬಂದಿದೆ.  
= ಗಣೇಶ .....(∵ ಣ್‌ + ಈ = ಣೇ)  
ತೀರ್ಮಾನ : ಅ ಕಾರಕ್ಕೆ ಈ ಕಾರೆ ಪರವಾದಾಗ ಏ ಕಾರೆ ಆದೇಶವಾಗಿ  
ಬರುವುದು.  

ಇದೇ ರೀತಿಯಾಗಿ,  
ದೇವ + ಇಂದ್ರ = ದೇವೇಂದ್ರ .....(ಅ + ಈ = ಎ)  
ಮಹಾ + ಈಶ್ವರೀ = ಮಹೇಶ್ವರೀ .....(ಆ + ಈ = ಎ)  
ಜನ + ಉಪಕಾರಿ = ಜನೋಪಕಾರಿ .....(ಅ + ಉ = ಓ)  
ಮಹ + ಉನ್ನತಿ = ಮಹೋನ್ನತಿ .....(ಅ + ಉ = ಓ)  
ರಾಜ + ಖುಹಿ = ರಾಜರ್ಹಿ .....(ಅ + ಖು = ಅರ್‌)  
ದೇವ + ಖುಹಿ = ದೇವರ್ಹಿ .....(ಅ + ಖು = ಅರ್‌)  

. ಈ ಉದಾಹರಣೆಗಳಲ್ಲಿ ಪೂರ್ವದ ಸ್ವರವು “ಅ” ಅಥವಾ “ಆ” ಆಗಿರುವುದು ;  
ಅವುಗಳಿಗೆ ಪರವಾಗಿರುವ ಸ್ವರಗಳು ಇ, ಈ, ಉ, ಖು ಆಗಿರುವು.  
ಅ, ಆಗಳಿಗೆ ಇ, ಈ ಗಳು ಪರವಾದಾಗ ಏಕಾರವೊ, ಅಕಾರಕ್ಕೆ ಉಕಾರ ಪರವಾದಾಗ ಓಕಾರವೂ,  
ಅಕಾರಕ್ಕೆ ಖುಕಾರ ಪರವಾದಾಗ “ಅರ್‌” ಕಾರೆವೂ, ಆದೇಶಗಳಾಗಿ ಬಂದಿರುವು.  
ಈ ತೆರೆನಾದ ಸಂಧಿಯು ಗುಣ ಸಂಧಿಯೆನಿಸುವುದು.
