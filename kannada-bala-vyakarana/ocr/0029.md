ಗಿರಿ + ಇಂದ್ರ = ಗಿರೀಂದ್ರ .....(ಇ + ಇ = ಈ)  
ಧ್ವಜ + ಆರೋಹಣ = ಧ್ವಜಾರೋಹಣ .....(ಅ + ಆ = ಆ)  
ಲಕ್ಷ್ಮೀ + ಈಶ = ಲಕ್ಷ್ಮೀಶ .....(ಈ + ಈ = ಈ)  

(೨) ಗುಣ ಸಂಧಿ :  
“ಗಣೇಶ” ಈ ಶಬ್ದವನ್ನು ಬಿಡಿಸಿ ನೋಡೋಣ.  
ಗಣೇಶ = ಗಣ + ಈಶ  
= ಗ + ಣ್‌ + (ಅ + ಈ) + ಶ  
ಇಲ್ಲಿ ಅ ಕಾರಕ್ಕೆ ಈ ಕಾರ ಪರವಾಗಿದೆ.  
= ಗ + ಣ್‌ + (ಏ) + ಶ  
ಇಲ್ಲಿ ಅ, ಈ ಗಳ ಸ್ಥಾನದಲ್ಲಿ ಏ ಕಾರ ಆದೇಶವಾಗಿ ಬಂದಿದೆ.  
= ಗಣೇಶ .....(∵ ಣ್‌ + ಈ = ಣೇ)  
ತೀರ್ಮಾನ : ಅ ಕಾರಕ್ಕೆ ಈ ಕಾರ ಪರವಾದಾಗ ಏ ಕಾರ ಆದೇಶವಾಗಿ  
ಬರುವುದು.  

ಇದೇ ರೀತಿಯಾಗಿ,  
ದೇವ + ಇಂದ್ರ = ದೇವೇಂದ್ರ .....(ಅ + ಇ = ಏ)  
ಮಹಾ + ಈಶ್ವರೀ = ಮಹೇಶ್ವರೀ .....(ಆ + ಈ = ಏ)  
ಜನ + ಉಪಕಾರಿ = ಜನೋಪಕಾರಿ .....(ಅ + ಉ = ಓ)  
ಮಹಾ + ಉನ್ನತಿ = ಮಹೋನ್ನತಿ .....(ಅ + ಉ = ಓ)  
ರಾಜ + ಋಷಿ = ರಾಜರ್ಷಿ .....(ಅ + ಋ = ಅರ್‌)  
ದೇವ + ಋಷಿ = ದೇವರ್ಷಿ .....(ಅ + ಋ = ಅರ್‌)  

. ಈ ಉದಾಹರಣೆಗಳಲ್ಲಿ ಪೂರ್ವದ ಸ್ವರವು “ಅ” ಅಥವಾ “ಆ” ಆಗಿರುವುದು ;  
ಅವುಗಳಿಗೆ ಪರವಾಗಿರುವ ಸ್ವರಗಳು ಇ, ಈ, ಉ, ಋ ಆಗಿರುವುವು.  
ಅ, ಆಗಳಿಗೆ ಇ, ಈ ಗಳು ಪರವಾದಾಗ ಏಕಾರವೂ, ಅಕಾರಕ್ಕೆ ಉಕಾರ ಪರವಾದಾಗ ಓಕಾರವೂ,  
ಅಕಾರಕ್ಕೆ ಋಕಾರ ಪರವಾದಾಗ “ಅರ್‌” ಕಾರವೂ, ಆದೇಶಗಳಾಗಿ ಬಂದಿರುವುವು.  
ಈ ತೆರನಾದ ಸಂಧಿಯು ಗುಣ ಸಂಧಿಯೆನಿಸುವುದು.
