ಉದಾಹರಣೆ ; ಗ್‌ + ಅ = ಗ, ಗ್‌ + ಆ = ಗಾ, ಗ್‌ + ಇ =  
ಗ್‌. ಈ = ಗೀ ಇತ್ಯಾದಿ. ಇಲ್ಲಿ ಗ್‌ ಅಗ್ರ ಗುಣಿತಾಕ್ಷರಗಳು,  
ಈ ರೀತಿಯಾಗಿ ಮೂವತ್ತನಾಲ್ಕು ವ್ಯಂಜನಗಳಿಗೂ ಸ್ವರಗಳನ್ನು ಸೇರಿಸಿ  
ಗುಣಿತಾಕ್ಷರಗಳನ್ನು ಬರೆಯಬಹುದು. ಬರವಣಿಗೆಯಲ್ಲಿ ಸ್ವರಗಳ ಬದ್ಧ ಸಂಕೇತಗಳನ್ನು  
ವ್ಯಂಜನಗಳಿಗೆ ಸೇರಿಸಿ ಗುಣಿತಾಕ್ಷರಗಳನ್ನು ಬರೆಯುವುದು ಪದ್ಯತಿ. ಕೆಳಗೆ ಕೊಟ್ಟಿರುವ  
ಪಟ್ಟಿಯಲ್ಲಿ «ಕ್‌» ವ್ಯಂಜನದ ಗುಣಿತಾಕ್ಷರಗಳನ್ನು ಮಾದರಿಗಾಗಿ ಕೊಟ್ಟಿದೆ.

| ೠ | ೄ | ಕ್‌ + ೠ = ಕೄ |
| ಎ | ೆ | ಕ್‌ + ಎ = ಕೆ |
| ಏ | ೇ | ಕ್‌ + ಏ = ಕೇ |
| ಐ | ೈ | ಕ್‌ + ಐ = ಕೈ |
