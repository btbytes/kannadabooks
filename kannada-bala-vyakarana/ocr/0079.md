ಉದಾಹರಣೆ : ಜೂಜುಗಾರ, ಕಲಾಕಾರ, ಕನ್ನಡಿಗ, ಹಣವಂತ,  
ಮಾಂತ್ರಿಕ, ಮಡಿವಾಳ, ಚಮ್ಮಾರ, ಹಾವಾಡಿಗ ಇತ್ಯಾದಿ ; ಇವು ಪುಲ್ಲಿಂಗ  
ತದ್ಧಿತಾಂತ ನಾಮಗಳು.  

೧. ಸ್ತ್ರೀಲಿಂಗದಲ್ಲಿ ಗಾತಿ, ವಂತೆ, ಗಿತ್ತಿ, ಇತಿ, ವತಿ,  
ಎ-ಇತ್ಯಾದಿ ತದ್ಧಿತ ಪ್ರತ್ಯಯಗಳು ನಾಮಪದಗಳ ಮೇಲೆ ಬಂದು ಸ್ತ್ರೀಲಿಂಗ  
ತದ್ಧಿತಾಂತ ನಾಮಗಳಾಗುವುವು. ಉದಾಹರಣೆಗೆ ಮೋಜುಗಾತಿ,  
ದಯಾವಂತೆ, ಹೂವಾಡಿಗಿತ್ತಿ, ಕನ್ನಡಿತಿ, ಗುಣವತಿ, ಜಾಣೆ ಇತ್ಯಾದಿ.  

(೨) ತದ್ಧಿತಾಂತ ಭಾವನಾಮ :  

ಷಷ್ಠೀ ವಿಭಕ್ತಿಗಳಾದ ನಾಮಪದಗಳ ಮೇಲೆ ಭಾವಾರ್ಥದಲ್ಲಿ ತನ,  
ಇಕೆ, ಮೆ, ಪು, ಉ ಇತ್ಯಾದಿ ತದ್ಧಿತ ಪ್ರತ್ಯಯಗಳು ಸೇರಿ ಆಗುವ ಹೊಸ  
ಶಬ್ದಗಳಿಗೆ ತದ್ಧಿತಾಂತ ಭಾವನಾಮಗಳೆಂದು ಹೆಸರು. ಉದಾ : ದಡ್ಡ ತನ.  

ವಿವರಣೆ : “ದಡ್ಡ” ಎಂಬ ನಾಮಪದದ ಷಷ್ಠೀ ವಿಭಕ್ತಿರೂಪ  
“ದಡ್ಡನ” ; ದಡ್ಡನ ಭಾವವೇ ದಡ್ಡ ತನ. ಇಲ್ಲಿ “ದಡ್ಡನ” ಎಂಬ ನಾಮಪದದ  
ಮುಂದೆ ಭಾವಾರ್ಥದಲ್ಲಿ “ತನ” ಎಂಬ ಪ್ರತ್ಯಯ ಸೇರಿ “ದಡ್ಡ ತನ” ಆಗಿರು  
ವುದು ; ಇದು ತದ್ಧಿತಾಂತ ಭಾವನಾಮ.  

ಇದೇ ರೀತಿಯಾಗಿ ಗೌಡಿಕೆ, ಜಾಣ್ಮೆ, ತಂಪು, ಕುರುಡು ಇವು  
ತದ್ಧಿತಾಂತ ಭಾವನಾಮಗಳು :  

ವಿಶ್ಲೇಷಣೆ :  

- ಗೌಡನ ಭಾವ ಗೌಡಿಕೆ (ಇಲ್ಲಿ “ಇಕೆ” ಪ್ರತ್ಯಯ ಸೇರಿದೆ).  
- ಜಾಣನ ಭಾವ ಜಾಣ್ಮೆ (ಇಲ್ಲಿ “ಮೆ” ಪ್ರತ್ಯಯ ಸೇರಿದೆ).  
- ತಣ್ಣನೆಯದರ ಭಾವ ತಂಪು (ಇಲ್ಲಿ “ಪು” ಪ್ರತ್ಯಯ ಸೇರಿದೆ).  
- ಕುರುಡನ ಭಾವ ಕುರುಡು (ಇಲ್ಲಿ “ಉ” ಪ್ರತ್ಯಯ ಸೇರಿದೆ).  

(೩) ತದ್ಧಿತಾಂತಾವ್ಯಯ  

- ಶಂಕರನ + ಅಂತೆ = ಶಂಕರನಂತೆ (ಪು.ಎ.)  
- ಗೌರಿಯ + ಅಂತೆ = ಗೌರಿಯಂತೆ (ಸ್ತ್ರೀ.ಎ.)  
- ಲತೆಯ + ಅಂತೆ = ಲತೆಯಂತೆ (ನ.ಎ.)  
- ಮಕ್ಕಳ + ಅಂತೆ = ಮಕ್ಕಳಂತೆ (ನ.ಬ.)
