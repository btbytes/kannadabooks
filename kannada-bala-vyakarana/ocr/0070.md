ಇದೇ ರೀತಿಯಾಗಿ ಅರಿಶಿನ ಕುಂಕುಮ, ಫಲ ಪುಷ್ಪ, ಗಿಡ ಮರ ಬಳ್ಳಿ
ಕೈಕಾಲು ಮುಖ, ಸೂರ್ಯ ಚಂದ್ರ ನಕ್ಷತ್ರ, ಗುಡುಗು ಸಿಡಿಲು ಮಿಂಚು
ಶಬ್ದ ಸ್ಪರ್ಶ ರೂಪ ರಸ ಗಂಧ-ದ್ವಂದ್ವ ಸಮಾಸ ಪದಗಳು.

(೬) ಬಹುವ್ರೀಹಿ ಸಮಾಸ :

“ಹಣೆಗಣ್ಣ” ಎಂಬ ಪದವನ್ನು ಹಣೆಯಲ್ಲಿ + ಕಣ್ಣುಳ್ಳವನು ಎಂದು
“ಫಾಲನೇತ್ರ” ಎಂಬ ಪದವನ್ನು ಫಾಲದಲ್ಲಿ + ನೇತ್ರವುಳ್ಳವನು ಎಂದು
ಬಿಡಿಸಿ ಬರೆಯಬಹುದು.

ಹಣೆಯಲ್ಲಿ + ಕಣ್ಣುಳ್ಳವನು = ಹಣೆಗಣ್ಣ

ಈ ಉದಾಹರಣೆಯಲ್ಲಿ ಪೂರ್ವಪದದ ಅರ್ಥವಾಗಲೀ ಉತ್ತರಪದದ
ಅರ್ಥವಾಗಲೀ ಪ್ರಧಾನವಲ್ಲ; ಹಣೆಯಲ್ಲಿ ಕಣ್ಣುಳ್ಳವನು ಯಾವನೋ ಅವನು
ಪ್ರಧಾನ. ಇದರಿಂದ ಸಮಾಸದ ಯಾವುದೊಂದು ಪದವೂ ಪ್ರಧಾನವಾಗಿ
ಅನ್ಯಪದದ ಅರ್ಥ ಪ್ರಧಾನವಾಗಿರುವುದೆಂದು ತಿಳಿದು ಬರುವುದು.
ಲಕ್ಷಣವುಳ್ಳ ಸಮಾಸಕ್ಕೆ ಬಹುವ್ರೀಹಿ ಸಮಾಸವೆಂದು ಹೆಸರು.

ವ್ಯಾಖ್ಯೆ: ಎರಡು ನಾಮಪದಗಳು ಸೇರಿ ಸಮಾಸವಾದಾಗ ಆ
ಪದದ ಅರ್ಥವು ಪ್ರಧಾನವಾಗಿ ಉಳ್ಳ ಸಮಾಸಕ್ಕೆ ಬಹುವ್ರೀಹಿ ಸಮಾಸವೆಂದು.

ಉದಾ:
- ಒಂದು + ಕಣ್ಣುಳ್ಳವ = ಒಕ್ಕಣ್ಣ
- ನಾಲ್ಕು + ಮೊಗವುಳ್ಳವ = ನಾಲ್ಮೊಗ
- ಕೆಂಪು + ಕಣ್ಣುಳ್ಳವ = ಕೆಂಗಣ್ಣ
- ಚಂದ್ರನಂತೆ + ಮುಖವುಳ್ಳವಳು = ಚಂದ್ರಮುಖಿ
- ವಜ್ರದಂತೆ + ಶರೀರವುಳ್ಳವ = ವಜ್ರಶರೀರಿ

(೭) ಕ್ರಿಯಾ ಸಮಾಸ:

ವ್ಯಾಖ್ಯೆ: ಪೂರ್ವಪದವು ಸಾಮಾನ್ಯವಾಗಿ ದ್ವಿತೀಯಾ ವಿಭಕ್ತಿ
ನಾಮಪದವಾಗಿದ್ದು ಕ್ರಿಯಾಸೂಚಕ ಉತ್ತರಪದದೊಂದಿಗೆ ಸೇರಿ ಆಗುವ
ಸಮಾಸಕ್ಕೆ ಕ್ರಿಯಾ ಸಮಾಸವೆಂದು ಹೆಸರು.
