ನಾವು, ಎಲ್ಲರೂ ಎಂಬ ಪದಗಳಲ್ಲಿ ವು, ಎ, ಅಕ್ಷರೆಗಳು ಒಂದಕ್ಕೊಂದು  
ಸೇರಿ ಸಂಧಿಯಾದಾಗ ಉ-ಕಾರವು ಕಾಣದಾಗುವುದು. ಇದನ್ನು ಉ-ಕಾರ  
ಲೋಪವಾಯಿತು ಎಂಬುದಾಗಿ ಹೇಳುತ್ತೇವೆ. ಹೀಗೆ  
ಸಂಧಿಕಾರ್ಯವು ನಡೆಯುವಾಗ ಒಂದು ಅಕ್ಷರವು ಬಿಟ್ಟು  
ಹೋಗುವುದಕ್ಕೆ “ಲೋಪ ಸಂಧಿ” ಎಂದು ಹೆಸರು.  

ನಿವರಣೆ : ಮೇಲಿನ ಉದಾಹರಣೆಯಲ್ಲಿ “ಉ” ಮತ್ತು “ಎ” ಸ್ವರಾಕ್ಷರ  
ಗಳು, ಹೀಗೆ, ಎರಡು ಸ್ವರಾಕ್ಷರಗಳು ಸಂಧಿಸುವಾಗ ಪದದ ಅರ್ಥ ಕೆಡದ  
ರೀತಿಯಲ್ಲಿ ನೊದಲನೆಯ ಸ್ವರಾಕ್ಷರವು ಲೋಪವಾಗುವುದು. ಯಾನ ಅಕ್ಷರ  
ಲೋಪವಾಗುವುದೋ ಆ ಅಕ್ಷರವನ್ನು ಸೇಂಸಿ ಸಂಧಿಯನ್ನು ಹೆಸರಿಸುವುದು  
ವಾಡಿಕೆಯಾಗಿದೆ. ಇಲ್ಲಿ ಉ-ಕಾರೆ ಲೋಪನಾಗಿರುವುದೆರಿಂದ, ಇದು. ಉ-ಕಾರ  
ಲೋಪ ಸಂಧಿ.  

ಉದಾ :  
- ಅಲ್ಲಿ + ಎ = ಅಲ್ಲಲ್ಲಿ, .... (ಇ-ಕಾರೆ ಲೋಪ ಸಂಧಿ)  
- ನನ್ನ + ಅಕೆ = ನನ್ನಾಕೆ, .... (ಅ-ಕಾರೆ ಲೋಪ ಸಂಧಿ)  
- ನನಗೆ + ಅಲ್ಲಿ = ನನಗೆಲ್ಲಿ, .... (ಎ-ಕಾರ ಲೋಪ ಸಂಧಿ)  

(೨) ಆಗಮ ಸಂಧಿ:  
“ಕಳ್ಳರು ಕುರಿಯನ್ನು ಕದ್ದರು” ಎಂಬ ವಾಕ್ಯದಲ್ಲಿ ಕುರಿಯನ್ನು ಎಂಬ  
ಸಂಧಿಪದವನ್ನು ಬಿಡಿಸಿ ನೋಡೋಣ. ಕುರಿ + ಅನ್ನು = ಕುರಿಯನ್ನು  
ಕುರಿ + ಅನ್ನು = ಕು. (ರ್ + ಇ) + (ಅ) + ನ್ನು  
ಕುರಿಯನ್ನು = ಕು + (ರ್ + ಇ + ಯ್ + ಅ) + ನ್ನು  

ಇಲ್ಲಿ ಸ್ವರದ ಮುಂದೆ ಸ್ವರ ಬಂದು ಸಂಧಿಕಾರ್ಯವಾಗುವುದನ್ನು ಕಾಣ  
ಬಹುದು. ಹಿಂದೆ ತಿಳಿಸಿರುವಂತೆ ಸಂಧಿವಾಡಿದಲ್ಲಿ ಕುರಿ + ಅನ್ನು = ಕುರೆನ್ನು
