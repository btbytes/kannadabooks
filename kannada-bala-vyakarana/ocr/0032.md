ಸೂತ್ರ : ಸಂಧಿ ಕಾರ್ಯದಲ್ಲಿ ಇ, ಈ, ಉ, ಊ, ಯ-ಕಾರೆಗಳು  
ಸವರ್ಣವಲ್ಲದ ಸ್ವರ ಸಂವಾದರೆ ಇ, ಈ ಕಾರಗಳಿಗೆ ಯ ಕಾರವೂ ಉ, ಆ  
ಕಾರಗಳಿಗೆ ವ್‌-ಕಾರವೂ ರ್‌-ಕಾರಕ್ಕೆ ರ್‌-ಕಾರವೂ ಆದೇಶಗಳಾಗಿ ಬರು  
ದಾದರೆ ಅದು ಯಣ್‌ ಸಂಧಿ ಎನಿಸುವುದು.  

| ಗತಿ - ಅಂತರೆ - ಗತ್ಯಂತೆರೆ . |  
ಅತಿ 4 ಅಂತೆ = ಅತ್ಯಂತ |  
ಆದಿ -- ಅಂತ —ಆಧ್ಯಂತ  
ಮನು ಅಂತರೆ ಮನ್ವಂತರ ನ  
: — ವ್ಯಂಜನ ಸಂಧಿಗಳು |  
(೧) ಜಶ್ತ್ವ ಸಂಧಿ:  
ನ ತ್ರಳಿಗೆ ತೊಟ್ಟಿರುವ ಉದಾಹರೆಣೆಗಳನ್ನು ನೋಡೋಣ.  
ದಿಕ್‌ + ದರ್ಶನ = ದಿಗ್‌ + ದರ್ಶನ = ದಿಗ್ದರ್ಶನ  
(ಕಕಾರಕ್ಕೆ ಗಕಾರಾದೇಶ)  
ಅಚ್‌ + ಅಂತ = ಅಜ್‌ + ಅಂತ = ಅಜಂತ  
ಷಟ್‌ + ಆನನ = ಷಡ್‌ + ಆನನ = ಷಡಾನನ  
(ಟಕಾರಕ್ಕೆ ದಕಾರಾದೇಶ)  
ಜಗತ್‌ + ಈಶ್ವರ = ಜಗದ್‌ + ಈಶ್ವರೆ = ಜಗದೀಶ್ವರ  
(ತಕಾರಕ್ಕೆ ದಕಾರಾದೇಶ)  
ಅಪ್‌ + ಜ = ಅಬ್‌ + ಜ = ಅಬ್ಬ  
(ಪಕಾರಕ್ಕೆ ಬಕಾರಾದೇಶ)  

ಇಲ್ಲಿ ಐದು ಉದಾಹರಣೆಗಳಿವೆ. ಈ ಉದಾಹರಣೆಗಳಲ್ಲಿ ಪೊರು  
ಶಬ್ದದ ಕೊನೆಯಲ್ಲಿರುವ ಕ್‌, ಚ್‌, ಟ್‌, ತ್‌, ಪ್‌ ಗಳಿಗೆ ಕ್ರಮವಾಗಿ  
ಗ್‌, ಜ್‌, ಡ್‌, ದ್‌, ಬ್‌ ಗಳಿಗೆ ಆದೇಶಗಳಾಗಿ ಬಂದು ಸಂಧಿಕೆಯೆ  
ವೇರ್ಪಟ್ಟಿದೆ. ಈ ತೆರನಾದ ಸಂಧಿಯು ಜಶ್ತ್ವ ಸಂಧಿ ಎನಿಸುವುದು.
