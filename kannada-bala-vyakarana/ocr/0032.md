ಸೂತ್ರ : ಸಂಧಿ ಕಾರ್ಯದಲ್ಲಿ ಇ, ಈ, ಉ, ಊ, ಋ-ಕಾರಗಳು  
ಸವರ್ಣವಲ್ಲದ ಸ್ವರ ಪರವಾದರೆ ಇ, ಈ ಕಾರಗಳಿಗೆ ಯ ಕಾರವೂ ಉ, ಊ  
ಕಾರಗಳಿಗೆ ವ್‌-ಕಾರವೂ ಋ-ಕಾರಕ್ಕೆ ರ್‌-ಕಾರವೂ ಆದೇಶಗಳಾಗಿ ಬರುವು  
ದಾದರೆ ಅದು ಯಣ್‌ ಸಂಧಿ ಎನಿಸುವುದು.  

| ಗತಿ + ಅಂತರ = ಗತ್ಯಂತರ |  
ಅತಿ + ಅಂತ = ಅತ್ಯಂತ |  
ಆದಿ + ಅಂತ = ಆದ್ಯಂತ  
ಮನು + ಅಂತರ = ಮನ್ವಂತರ  
: — ವ್ಯಂಜನ ಸಂಧಿಗಳು |  
(೧) ಜಶ್ತ್ವ ಸಂಧಿ:  
ಕೆಳಗೆ ಕೊಟ್ಟಿರುವ ಉದಾಹರಣೆಗಳನ್ನು ನೋಡೋಣ.  
ದಿಕ್‌ + ದರ್ಶನ = ದಿಗ್‌ + ದರ್ಶನ = ದಿಗ್ದರ್ಶನ  
(ಕಕಾರಕ್ಕೆ ಗಕಾರಾದೇಶ)  
ಅಚ್‌ + ಅಂತ = ಅಜ್‌ + ಅಂತ = ಅಜಂತ  
ಷಟ್‌ + ಆನನ = ಷಡ್‌ + ಆನನ = ಷಡಾನನ  
(ಟಕಾರಕ್ಕೆ ದಕಾರಾದೇಶ)  
ಜಗತ್‌ + ಈಶ್ವರ = ಜಗದ್‌ + ಈಶ್ವರ = ಜಗದೀಶ್ವರ  
(ತಕಾರಕ್ಕೆ ದಕಾರಾದೇಶ)  
ಅಪ್‌ + ಜ = ಅಬ್‌ + ಜ = ಅಬ್ಜ  
(ಪಕಾರಕ್ಕೆ ಬಕಾರಾದೇಶ)  

ಇಲ್ಲಿ ಐದು ಉದಾಹರಣೆಗಳಿವೆ. ಈ ಉದಾಹರಣೆಗಳಲ್ಲಿ ಪೂರ್ವ  
ಶಬ್ದದ ಕೊನೆಯಲ್ಲಿರುವ ಕ್‌, ಚ್‌, ಟ್‌, ತ್‌, ಪ್‌ ಗಳಿಗೆ ಕ್ರಮವಾಗಿ  
ಗ್‌, ಜ್‌, ಡ್‌, ದ್‌, ಬ್‌ ಗಳು ಆದೇಶಗಳಾಗಿ ಬಂದು ಸಂಧಿಕಾರ್ಯ  
ವೇರ್ಪಟ್ಟಿದೆ. ಈ ತೆರನಾದ ಸಂಧಿಯು ಜಶ್ತ್ವ ಸಂಧಿ ಎನಿಸುವುದು.
