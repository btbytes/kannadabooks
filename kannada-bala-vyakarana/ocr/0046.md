ಈ ಉದಾಹರಣೆಗಳಲ್ಲಿ ಏಕವಚನ ಶಬ್ದಗಳಿಗೆ “ಗಳು” ಎಂಬ ಆಗಮ  
ಸೇರಿ ಬಹುವಚನ ಶಬ್ದಗಳಾಗಿರುವುದು ಕಂಡುಬರುತ್ತದೆ. ಆಳು, ಹಸು,  
ರೂಪಾಯಿ, ಗಿಣಿ—ಇವು ನಪುಂಸಕ ಲಿಂಗ ಶಬ್ದಗಳು. ಆದುದರಿಂದ  
ನಪುಂಸಕ ಲಿಂಗ ಶಬ್ದಗಳಿಗೆ ಬಹುವಚನದಲ್ಲಿ “ಗಳು” ಎಂಬ ಆಗಮ  
ಸೇರುತ್ತದೆಂದು ತಿಳಿಯಬಹುದು.  

ವಿಶೇಷ ಸಂದರ್ಭ : ಅಕಾರಾಂತವಲ್ಲದ ಪುಲ್ಲಿಂಗ ಹಾಗೂ ಸ್ತ್ರೀಲಿಂಗ  
ಶಬ್ದಗಳಿಗೆ “ಗಳು” ಎಂಬ ಆಗಮ ಸೇರಿ ಬಹುವಚನ ರೂಪಗಳಾಗುವುದು.  
ಉದಾ :  
- ಗಂಡು + ಗಳು = ಗಂಡುಗಳು  
- ಹೆಣ್ಣು + ಗಳು = ಹೆಣ್ಣುಗಳು  

□ ಏಕವಚನದಲ್ಲಿರುವ ಪುಲ್ಲಿಂಗ, ಸ್ತ್ರೀಲಿಂಗ ಶಬ್ದಗಳಿಗೆ ಸಾಮಾನ್ಯ  
ವಾಗಿ “ಅರು” ಎಂಬ ಆಗಮ ಸೇರಲು ಬಹುವಚನ ರೂಪವುಂಟಾಗುವುದು.  
ಉದಾ :  
- ಅರಸ + ಅರು = ಅರಸರು (ಬ.ವ.)  
- ಹುಡುಗ + ಅರು = ಹುಡುಗರು  
- ಮುದುಕಿ + ಅರು = ಮುದುಕಿಯರು  
- ತಂಗಿ + ಅರು = ತಂಗಿಯರು  

□ ಏಕವಚನದಲ್ಲಿರುವ ಕೆಲವು ಪುಲ್ಲಿಂಗ, ಸ್ತ್ರೀಲಿಂಗ ಅಕಾರಾಂತ  
ಬಂಧುವಾಚಕ ಶಬ್ದಗಳಿಗೆ “ಅಂದಿರು” ಎಂಬ ಆಗಮ ಸೇರಲು ಬಹುವಚನ  
ರೂಪವುಂಟಾಗುವುದು.  
ಉದಾ :  
- ಅಣ್ಣ + ಅಂದಿರು = ಅಣ್ಣಂದಿರು (ಬ.ವ.)  
- ಅಳಿಯ + ಅಂದಿರು = ಅಳಿಯಂದಿರು  
- ಅಕ್ಕ + ಅಂದಿರು = ಅಕ್ಕಂದಿರು  
- ತಾಯಿ + ಅಂದಿರು = ತಾಯಂದಿರು  

□ ಕೆಲವು ಏಕವಚನ ಶಬ್ದಗಳಿಗೆ ಕಳು, ವು ಮೊದಲಾದ ಆಗಮಗಳು  
ಸೇರಿ ಬಹುವಚನ ರೂಪಗಳಾಗುವುದು.
