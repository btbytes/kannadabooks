ಸೂತ್ರ : ಸಂಧಿಕಾರ್ಯ ನಡೆಯುವಾಗ ಅ, ಆ ಕಾರಗಳಿಗೆ  
ಕರಳು ಪರವಾದರೆ “ಏ” ಕಾರವೂ, ಉ, ಊ ಕಾರಗಳು ಪರವಾದ  
ಕಾರವು ಋಕಾರವು ಪರವಾದರೆ “ಅರ್” ಕಾರವೂ ಆದೇಶಗಳಾಗಿ ಬರುವುವು.  
ಅದು ಗುಣಸಂಧಿ ಎನಿಸುವುದು.  

(೩) ವೃದ್ಧಿ ಸಂಧಿ :  
“ಏಕೈಕ” — ಈ ಶಬ್ದವನ್ನು ಬಿಡಿಸಿ ನೋಡೋಣ.  
ಏಕೈಕ = ಏಕ + ಏಕ  
= ಏಕ್ + (ಅ + ಏ) + ಕ  
ಇಲ್ಲಿ ಅ ಕಾರಕ್ಕೆ ಏ ಕಾರ ಪರವಾಗಿದೆ.  
ಇಲ್ಲಿ ಅ, ಏ ಗಳ ಸ್ಥಾನದಲ್ಲಿ “ಐ” ಕಾರ ಆದೇಶವಾಗಿ ಬಂದಿದೆ.  
= ಏಕೈಕ (“ಕ್” — ಐಕ್)  

ತೀರ್ಮಾನ : ಅಕಾರಕ್ಕೆ ಏಕಾರ ಪರವಾದಾಗ ಐಕಾರ ಆದೇಶವಾಗಿ  
ಬರುವುದು.  

ಇದೇ ರೀತಿಯಾಗಿ,  
ಅಷ್ಟ + ಐಶ್ವರ್ಯ = ಅಷ್ಟೈಶ್ವರ್ಯ (ಅ + ಐ = ಐ)  
ವನ + ಓಷಧಿ = ವನೌಷಧಿ (ಅ + ಓ = ಔ)  
ಮಹಾ + ಔದಾರ್ಯ = ಮಹೌದಾರ್ಯ (ಆ + ಔ = ಔ)  
ಭಾವ + ಐಕ್ಯತೆ = ಭಾವೈಕ್ಯತೆ (ಅ + ಐ = ಐ)  

ಈ ಉದಾಹರಣೆಗಳಲ್ಲಿ ಪೂರ್ವದ ಸ್ವರವು ಅ ಅಥವಾ ಆ ಆಗಿರುವುದು;  
ಅವುಗಳಿಗೆ ಪರವಾಗಿರುವ ಸ್ವರಗಳು ಏ, ಐ, ಓ, ಔ ಆಗಿರುವುವು. ಅ, ಆ  
ಗಳಿಗೆ ಏ, ಐ ಗಳು ಪರವಾದಾಗ “ಐ” ಕಾರವೂ ಓ, ಔ ಗಳು ಪರವಾದಾಗ  
“ಔ” ಕಾರವೂ ಆದೇಶಗಳಾಗಿ ಬಂದಿರುವುವು. ಈ ತೆರನಾದ ಸಂಧಿಯು  
ವೃದ್ಧಿ ಸಂಧಿಯೆನಿಸುವುದು.
