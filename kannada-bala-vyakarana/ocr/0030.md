ಸೂತ್ರ : ಸೇಧಿಕಾರ್ಯ ನಡೆಯುವಾಗ ಅ, ಆ ಕಾರಗಳಿಗೆ  
ಕರಳು ಪರವಾದನೆ “ಏ” ಕಾರವೂ, ಉ, ಊ ಕಾರಗಳು ಪರವಾದ  
ಕಾರವು ಹಕಾರವು ಪರವಾದರೆ “ಅರ್” ಕಾರವೂ ಆದೇಶಗಳಾಗಿ ಬರುವು.  
ಆದು ಗುಣಸಂಧಿ ವಿನಿಸುವುದು.  

(೩) ವೃದ್ಧಿ ಸಂಧಿ :  
“ಏಕೈಕ” — ಈ ಶಬ್ದವನ್ನು ಬಿಡಿಸಿ ನೋಡೋಣ.  
ಏಕೈಕ = ಏಕ + ಏಕ  
= ಏಕ್ + (ಅ + ಏ) + ಕ  
ಇಲ್ಲಿ ಅ ಕಾರಕ್ಕೆ ಏ ಕಾರ ಪರೆವಾಗಿದೆ.  
ಇಲ್ಲಿ ಅ, ಏ ಗಳ ಸ್ಥಾನದಲ್ಲಿ “ಐ” ಕಾರೆ ಆದೇಶವಾಗಿ ಬಂದಿದೆ.  
= ಏಕೈಕ (“ಕ್” — ಐಕ್)  

ತೀರ್ಮಾನ : ಅಕಾರಕ್ಕೆ ಏಕಾರೆ ಪರನಾದಾಗ ಐಕಾರೆ ಆದೇಶವಾಗಿ  
ಬರುವುದು.  

ಇದೇ ರೀತಿಯಾಗಿ,  
ಅಷ್ಟ. ಐಶ್ವರ್ಯ = ಅಸ್ಟೈಶ್ವರ್ಯ (ಅ + ಐ = ಐ)  
ವನ - ಓಷಧಿ = ವನೌಷಧಿ (ಅ + ಓ = ಓ)  
ಮಹಾ - ಔದಾರ್ಯ = ಮಹೌದಾರ್ಯ (ಆ + ಔ = ಔ)  
ಭಾವ - ಐಕ್ಯತೆ = ಭಾವೈಕ್ಯತೆ (ಆ + ಐ = ಐ)  

ಈ ಉದಾಹರಣೆಗಳಲ್ಲಿ ಪೂರ್ವದ ಸ್ವರವು ಅ ಅಥವಾ ಆ ಆಗಿರುವುದು;  
ಅವುಗಳಿಗೆ ಪರವಾಗಿರುವ ಸ್ವರಗಳು ಏ, ಐ, ಓ, ಔ ಆಗಿರುವುವು. ಅ, ಆ  
ಗಳಿಗೆ ಏ, ಐ ಗಳು ಸವಾದಾಗ “ಐ” ಕಾರವೂ ಓ, ಔ ಗಳು ಪರವಾದಾಗ  
ಆಕ್ಟಾ: ಕಾರವೂ ಆದೇಶಗಳಾಗಿ ಬಂದಿರುವುವು. ಈ ತೆರೆನಾದ ಸಂಧಿಯು  
ವೃದ್ಧಿ ಸಂಧಿಯೆನಿಸುವುದು.
