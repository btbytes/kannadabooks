**ಉದಾ :**  
ತಲೆಯ + ಮುಂದು = ಮುಂದಲೆ  
ಕೈಯ + ಅಡಿ = ಅಂಗೈ  
ಕಾಲು + ಅಡಿ = ಅಂಗಾಲು  
ಕಣ್ಣ + ಕಡೆ = ಕಡೆಗಣ್ಣು  
ಮೈಯ + ಒಳಗು = ಒಳಮೈ  
ಇರುಳಿನ + ನಡು = ನಟ್ಟಿರುಳು  
ತುಟಿಯ + ಕೆಳಗು = ಕೆಳದುಟಿ  

(೫) ದ್ವಂದ್ವ ಸಮಾಸ :  
“ಮಳೆ ಬಂದು ಕೆರೆಕಟ್ಟೆ ತುಂಬಿತು.”—  
ಈ ವಾಕ್ಯದಲ್ಲಿ ದಪ್ಪಕ್ಷರಗಳಲ್ಲಿರುವ “ಕೆರೆಕಟ್ಟೆ” ಎಂಬ ಪದವನ್ನು  
ಕೆರೆಯೂ ಕಟ್ಟೆಯೂ ಎಂದು ಬಿಡಿಸಿ ಬರೆಯಬಹುದು.  
ಕೆರೆಯೂ ಕಟ್ಟೆಯೂ – ಕೆರೆಕಟ್ಟೆ  
ಇಲ್ಲಿ ಕೆರೆಯೂ ಮತ್ತು ಕಟ್ಟೆಯೂ ಒಂದಕ್ಕೊಂದು ಪೂರಕವಾಗಿರುವ  
ಅಥವಾ ಸಹಯೋಗ ಹೊಂದಿರುವ ಎರಡು ಪದಗಳು. ಇವುಗಳಲ್ಲಿ ಯಾವು  
ದೊಂದು ಪದದ ಅರ್ಥವು ಗೌಣವಲ್ಲ, ಎರಡು ಪದಗಳ ಅರ್ಥವೂ  
ಪ್ರಧಾನವೇ ಸರಿ. ಇಂತಹ ಪದಗಳು ಸೇರಿ ಆಗುವ ಸಮಾಸಕ್ಕೆ ದ್ವಂದ್ವ  
ಸಮಾಸವೆನ್ನುವರು.  

ವ್ಯಾಖ್ಯೆ :- ಸಹಯೋಗವಿರುವ ಎರಡು ಅಥವಾ ಹೆಚ್ಚು ನಾಮ  
ಪದಗಳು ಒಂದಕ್ಕೊಂದು ಸೇರಿ ಎಲ್ಲ ಪದಗಳ ಅರ್ಥವೂ ಪ್ರಧಾನವಾಗಿಯುಳ್ಳ  
ಸಮಾಸಕ್ಕೆ ದ್ವಂದ್ವ ಸಮಾಸವೆಂದು ಹೆಸರು.  

ಉದಾ : ತಾಯಿಯೂ-ತಂದೆಯೂ = ತಾಯಿತಂದೆ  
ಹಣ್ಣನ್ನೂ-ಕಾಯಿಯನ್ನೂ = ಹಣ್ಣುಕಾಯಿ  
ಹಸುವನ್ನೂ-ಕರುವನ್ನೂ = ಹಸುಕರು
