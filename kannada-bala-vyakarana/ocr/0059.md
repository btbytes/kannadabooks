ಮಾಡು + ಅದು = ಮಾಡದು ; ಮಾಡು + ಅವು = ಮಾಡವು  
ಮಾಡು + ಎ = ಮಾಡೆ ; ಮಾಡು + ಅರಿ = ಮಾಡಿರಿ  
ಮಾಡು + ಎನು = ಮಾಡೆನು ; ಮಾಡು + ಎವು = ಮಾಡೆವು  

ಇವು “ಮಾಡು” ಧಾತುವಿನ ಮೇಲೆ ಹಲವು ಪ್ರತ್ಯಯಗಳು ಸೇರಿ  
“ಕ್ರಿಯೆಯು ನಡೆಯದು” ಎಂಬ ಅರ್ಥ ಕೊಡುವ ಕ್ರಿಯಾಪದಗಳಾಗಿರುವುವು.  
ಹೀಗೆ, ಕ್ರಿಯೆಯು ನಡೆಯದು ಎಂಬರ್ಥ ಕೊಡುವ ಕ್ರಿಯಾಪದಗಳಿಗೆ  
ನಿಷೇಧಾರ್ಥಕ ಕ್ರಿಯಾಪದಗಳೆಂದು ಹೆಸರು.  

: ಧಾತುಗಳ ಮೇಲೆ ಏಕವಚನದಲ್ಲಿ ಅನು, ಅಳು, ಅದು, ಎ, ಎನು  
ಎಂಬ ಆಖ್ಯಾತ ಪ್ರತ್ಯಯಗಳೂ ಬಹುವಚನದಲ್ಲಿ ಅರು, ಅವು, ಅರಿ, ಎವು  
ಎಂಬ ಆಖ್ಯಾತ ಪ್ರತ್ಯಯಗಳೂ ಸೇರಿ ನಿಷೇಧಾರ್ಥಕ ಕ್ರಿಯಾಪದಗಳಾಗುವುವು.  

(6) ಸಂಭಾವನಾರ್ಥಕ ಕ್ರಿಯಾಪದಗಳು  
ಉದಾಹರಣೆ : “ಕೊಡು” ಧಾತು  

| ಏಕವಚನ | ಬಹುವಚನ |  
| --- | --- |  
| ಕೊಡು + ಆನು = ಕೊಟ್ಟಾನು | ಕೊಡು + ಆರು = ಕೊಟ್ಟಾರು |  
| ಕೊಡು + ಆಳು = ಕೊಟ್ಟಾಳು | ಕೊಡು + ಆರು = ಕೊಟ್ಟಾರು |  
| ಕೊಡು + ಈತು = ಕೊಟ್ಟೀತು | ಕೊಡು + ಆವು = ಕೊಟ್ಟಾವು |  
| ಕೊಡು + ಈಯೇ = ಕೊಟ್ಟೀಯೆ | ಕೊಡು + ಈರಿ = ಕೊಟ್ಟೀರಿ |  
| ಕೊಡು + ಏನು = ಕೊಟ್ಟೇನು | ಕೊಡು + ಏವು = ಕೊಟ್ಟೇವು |  

[ಗಮನಿಸಿ : “ಕೊಡು” ಧಾತುವಿನ ಮೇಲೆ ಸಂಭಾವನಾರ್ಥಕ  
ಆಖ್ಯಾತ ಪ್ರತ್ಯಯಗಳು ಸೇರಿದಾಗ ಧಾತುವಿನ ಕೊನೆಯ “ಡು” ಕಾರಕ್ಕೆ  
“ಟ್ಟ” ಕಾರ ಆದೇಶವಾಗಿ ಬರುವುದು.]  

ಇಲ್ಲಿ “ಕೊಡು” ಧಾತುವಿನ ಮೇಲೆ ಹಲವು ಪ್ರತ್ಯಯಗಳು ಸೇರಿ  
“ಕ್ರಿಯೆಯು ಸಂಭವಿಸುವಲ್ಲಿ ಸಂಶಯತೋರುವ” ಕ್ರಿಯಾಪದಗಳಾಗಿರುವುವು.
