ಸಂಧಿ-ಇವು ಸ್ವರ ಸಂಧಿಗಳು. ವ್ಯಂಜನ ಸಂಧಿಗಳಲ್ಲಿ ಮುಖ್ಯವಾದವುಗಳು  
(೧) ಜಶ್ತ್ವ ಸಂಧಿ, (೨) ಶ್ಚುತ್ವ ಸಂಧಿ, ಮತ್ತು (೩) ಅನುನಾಸಿಕ ಸಂಧಿ.  
ಈ ಸಂಧಿಗಳಿಗೆ ಅನ್ವಯಿಸುವ ಸೂತ್ರಗಳನ್ನು ಉದಾಹರಣೆಗಳ ಸಹಿತ  
ತಿಳಿಯೋಣ.  

— ಸ್ವರ ಸಂಧಿಗಳು —  

(೧) ಸವರ್ಣದೀರ್ಘ ಸಂಧಿ :  
(ಅ, ಆ); (ಇ, ಈ); (ಉ, ಊ); (ಋ, ೠ); (ಎ, ಏ);  
(ಒ, ಓ)-ಇವು ಒಂದೇ ಜಾತಿಯ ಸ್ವರಗಳನ್ನುಳ್ಳ ಆರು ಜೊತೆ ಅಕ್ಷರಗಳು.  
ಇವುಗಳಿಗೆ ಸವರ್ಣ ಸ್ವರಗಳೆಂದು ಹೆಸರು. ಈ ಹಿನ್ನೆಲೆಯಲ್ಲಿ “ದೇವಾಸುರೆ”  
ಎಂಬ ಶಬ್ದದಲ್ಲಿನ ಸಂಧಿಕಾರ್ಯವನ್ನು ನೋಡೋಣ.  

``  
ದೇವಾಸುರೆ = ದೇವ + ಅಸುರ  
= ದೇ + ವ್‌ + (ಅ + ಅ) + ಸುರ  
``  

ಇಲ್ಲಿ “ಅಕಾರಕ್ಕೆ” ಅಕಾರ ಪರವಾಗಿದೆ ; ಇವು ಸವರ್ಣ ಸ್ವರಗಳು.  

``  
= ದೇ + ವ್‌ + (ಆ) + ಸುರ  
``  

ಇಲ್ಲಿ ಅ, ಅಗಳ ಸ್ಥಾನದಲ್ಲಿ “ಆ” ಕಾರ ಆದೇಶವಾಗಿ ಬಂದಿದೆ.  

``  
= ದೇವಾಸುರ (ವ್‌ + ಆ = ವಾ)  
``  

ಇಲ್ಲಿ ಎರಡು ಸವರ್ಣ ಸ್ವರಗಳಿಗೆ ಒಂದೇ ದೀರ್ಧ ಸ್ವರವು ಆದೇಶವಾಗಿ  
ಬಂದಿದೆ. ಇದನ್ನು ಸವರ್ಣದೀರ್ಧ ಸಂಧಿ ಎನ್ನುವರು.  

ಸೂತ್ರ : ಸವರ್ಣ ಸ್ವರಗಳು ಪರವಾದಾಗ (ಒಂದರ ಮುಂದೆ  
ಮತ್ತೊಂದು ಬಂದಾಗ) ಅವೆರಡರ ಸ್ಥಾನದಲ್ಲಿ ಅದೇ ಜಾತಿಯ ದೀರ್ಧ  
ಸ್ವರವು ಆದೇಶವಾಗಿ ಬರುವುದು. ಇದನ್ನು ಸವರ್ಣ ದೀರ್ಧ ಸಂಧಿಯೆನ್ನುವರು.  

ಉದಾಹರಣೆ :  
``  
ಗುರು + ಉಪದೇಶ = ಗುರೂಪದೇಶ .... (ಉ + ಉ = ಊ)  
ಸ್ವರ + ಅಕ್ಷರ = ಸ್ವರಾಕ್ಷರ .... (ಅ + ಅ = ಆ)  
ಗಿರಿ + ಈಶ = ಗಿರೀಶ .... (ಇ + ಈ = ಈ)  
```
