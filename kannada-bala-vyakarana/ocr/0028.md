ಸಂಧಿ-ಇವು ಸ್ಕರ ಸಂಧಿಗಳು. ವ್ಯಂಜನ ಸಂಧಿಗಳಲ್ಲಿ ಮುಖ್ಯವಾದವುಗಳು  
(೧) ಜಶ್ಚ್ಯ ಸಂಧಿ, (೨) ಶ್ಪುತ್ತೃ ಸಂಧಿ, ಮತ್ತು (೩) ಅನುನಾಸಿಕ ಸಂಧಿ.  
ಈ ಸಂಧಿಗಳಿಗೆ ಅನುವಯಿಸುವ ಸೂತ್ರಗಳನ್ನು ಉದಾಹರಣೆಗಳ ಸಹಿತ  
ತಿಳಿಯೋಣ.  

— ಸ್ವರ ಸಂಧಿಗಳು —  

(೧) ಸವರ್ಣಧೀರ್ಧ ಸಂಧಿ :  
(ಅ, ಆ); (ಇ, ಈ); (ಉ, ಊ); (ಋ, ಋ); (ಎ, ಏ);  
(ಒ, ಓ)-ಇವು ಒಂದೇ ಜಾತಿಯ ಸ್ವರಗಳನ್ನುಳ್ಳೆ ಆರು ಜೊತೆ ಅಕ್ಷರಗಳು.  
ಇವುಗಳಿಗೆ ಸವರ್ಣ ಸ್ವರಗಳೆಂದು ಹೆಸರು. ಈ ಹಿನ್ನೆಲೆಯಲ್ಲಿ “ದೇವಾಸುರೆ”  
ಎಂಬ ಶಬ್ದದಲ್ಲಿನ ಸಂಧಿಕಾರ್ಯವನ್ನು ನೋಡೋಣ.  

``  
ದೇವಾಸುರೆ = ದೇವ + ಅಸುರ  
= ದೇವ + ವ್‌-(ಅ--ಅ)-ಸುರ  
``  

ಇಲ್ಲಿ “ಅಕಾರಕ್ಕೆ” “ಅಕಾರ ಸರವಾಗಿದೆ ; ಇವು ಸವರ್ಣ ಸ್ವರಗಳು.  

``  
= ದೇವ + ವ್‌-(ಆ)-ಸುರ  
``  

ಇಲ್ಲಿ ಅ, ಅಗಳ ಸ್ಥಾನದಲ್ಲಿ «ಆ» ಕಾರೆ ಆದೇಶವಾಗಿ ಬಂದಿದೆ.  

``  
= ದೇವಾಸುರೆ (ವ್‌ + ಆವಾ)  
``  

ಇಲ್ಲಿ ಎರಡು ಸವರ್ಣ ಸ್ವರಗಳಿಗೆ ಒಂದೇ ದೀರ್ಧ ಸ್ವರವು ಆದೇಶವಾಗಿ  
ಬಂದಿದೆ. ಇದನ್ನು ಸವರ್ಣದೀರ್ಧ ಸಂಧಿ ಎನ್ನುವರು.  

ಸೂತ್ರ : ಸವರ್ಣ ಸ್ವರಗಳು ಸವಾದಾಗ (ಒಂದರೆ ಮುಂದೆ  
ಮತ್ತೊಂದು ಬಂದಾಗ) ಅನೆರಡರೆ ಸ್ಥಾನದಲ್ಲಿ ಅಭೀ ಜಾತಿಯ ದೀರ್ಧ  
ಸ್ವರವು ಆದೇಶವಾಗಿ ಬರುವುದು. ಇದನ್ನು ಸವರ್ಣ ದೀರ್ಧ ಸಂಧಿಯೆನ್ನುವರು.  

ಉದಾಹರಣೆ :  
``  
ಗುರು + ಉಪದೇಶ = ಗುರೂಪದೇಶ .... (ಉ + ಉ = ಊ)  
ಸ್ವ + ಅಕ್ಷರೆ = ಇಸ್ವರಾಕ್ಷರ .... (ಅ + ಅ = ಆ)  
ಗಿರಿ + ಈಶೆ = ಗಿರೀಶ .... (ಈ + ಈ = ಈ)  
```
