ಸಾಠ ೫ : ಕ್ರಿಯಾಪದ  

ಕ್ರಿಯೆಯ ಅರ್ಥವನ್ನು ಕೊಡುವ ಪದವೇ ಕ್ರಿಯಾಪದ; ಇದು ೪  
ನಿರ್ವಹಿಸುವ ಕೆಲಸವನ್ನು ತಿಳಿಸುತ್ತದೆ.  

ಕುಡುರೆಯು ಓಡುತ್ತಿದೆ; ಪದ್ಮಿ ನಿಯು ಹಾಡುತ್ತಾಳೆ ; ನಾಬಿ:  
ಕೊಟ್ಟಿಯನ್ನು ತಿನ್ನುತ್ತದೆ ; ಮಂಜುನಾಥನು ಕಾಲ್ಚೆಂಡಿನ ಆಟ;  
ಆಡುತ್ತಾನೆ--ಈ ವಾಕ್ಯಗಳಲ್ಲಿರುವ ಕ್ರಿಯಾಪದಗಳೆಂದೆ ಓಡು,  
ಹಾಡುತ್ತಾಳೆ, ತಿನ್ನುತ್ತದೆ, ಆಡುತ್ತಾನೆ. ಈ ಕ್ರಿಯಾಪದಗಳನ್ನು ೬  

ಓಡುತ್ತಿದೆ = ಓಡು + ಉತ್ತ + ಇದೆ  
ಹಾಡುತ್ತಾಳೆ = ಹಾಡು + ಉತ್ತ + ಆಳೆ  
ತಿನ್ನುತ್ತದೆ = ತಿನ್ನು + ಉತ್ತ + ಅದಿ  
ಆಡುತ್ತಾನೆ = ಆಡು + ಉತ್ತ + ಆನೆ  

ಇಲ್ಲಿ “ಓಡು” ಎಂಬುದು “ಓಡುತ್ತಿದೆ” ಎಂಬ ಕ್ರಿಯಾಪದದ ವ.  
ರೂಪ; ಇದು ಸ್ವತಂತ್ರವಾದ ಅರ್ಥನನ್ನು ಹೊಂದಿರುವ ಶಬ್ದ. ಕ್ರಿಯೆ  
ಅರ್ಥವನ್ನು ಕೊಡುವ, ಆದರೆ ಪ್ರತ್ಯಯವನ್ನು ಹೊಂದಿರದ ಈ ಶಃ  
ಕ್ರಿಯಾಪ್ರಕೃತಿಯಾಗಿರುವುದು. ಕ್ರಿಯಾಪ್ರಕೃತಿಯನ್ನು “ಧಾತು” ಎ  
ದಾಗಿಯೂ ಕರೆಯುವುದುಂಟು. ಕ್ರಿಯಾಪ್ರಕೃತಿಯ ಮುಂದಿರುವ ಉತ್ತ,  
ಎಂಬುವು ಪ್ರತ್ಯಯಗಳು. “ಉತ್ತ” ಎಂಬುದನ್ನು “ಕಾಲ ಸೂ  
ಸ್ರತ್ಯಯ”ನೆಂತಲೂ, “ಇದೆ” ಎಂಬುದನ್ನು ಆಖ್ಯಾತ ಪ್ರತ್ಯಯವೇಂ  
ಹೇಳುತ್ತೇವೆ.
