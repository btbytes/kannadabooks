ಮೇಲೆ ಕೊಟ್ಟಿರುವ ಉದಾಹರಣೆಗಳಲ್ಲಿ ಓಡು, ಹಾಡು, ತಿನ್ನು, ಆಡು  
ಕ್ರಿಯಾಪ್ರಕೃತಿಗಳು ಅಥವಾ ಧಾತುಗಳು ; “ಉತ್ತ” ಎಂಬುದು ಕಾಲಸೂಚಕ  
ಪ್ರತ್ಯಯ ಮತ್ತು ಇದೆ, ಆಳೆ, ಅದೆ, ಆನೆ ಆಖ್ಯಾತ ಪ್ರತ್ಯಯಗಳು. ಸೂತ್ರ  
ರೂಪದಲ್ಲಿ ಹೇಳುವುದಾದರೆ,  
ಕ್ರಿಯಾ = ಕ್ರಿಯಾ + ಕಾಲಸೂಚಕ + ಆಖ್ಯಾತ  
ಪದ + ಪ್ರಕೃತಿ + ಪ್ರತ್ಯಯ + ಪ್ರತ್ಯಯ  
ವಿಶೇಷ ಸೂಚನೆ : ಕೆಲವು ನಾಮಶ್ರಕೃತಿಗಳನ್ನು ಮತ್ತು ಅನುಕರಣ  
ಶಬ್ದಗಳನ್ನು ಧಾತುಗಳಂತೆ ಬಳಸುವುದುಂಟು. ನಾಮಶ್ರಕೃತಿಯ ಮೇಲಾಗಲೀ  
ಅನುಕರಣ ಶಬ್ದದ ಮೇಲಾಗಲೀ “ಇಸು” ಪ್ರತ್ಯಯ ಸೇರೆಲು ಅದು ಧಾತು  
ವೆನಿಸುವುದು. ಅಂತಹೆ ಧಾತುಗಳಿಗೆ ಪ್ರತ್ಯಯಾಂತ ಧಾತುಗಳೆಂದು ಹೆಸರು.  
ಉದಾಹರಣೆ :  
ಕನ್ನಡ + ಇಸು = ಕನ್ನಡಿಸು (ಪ್ರತ್ಯಯಾಂತ ಧಾತು)  
ಉತ್ತರ + ಇಸು = ಉತ್ತರಿಸು ( ೨ )  
“ಪ್ರಯತ್ನ + ಇಸು = ಪ್ರಯತ್ನಿಸು ( ೨ )  
ಸಿದ್ಧಿ + ಇಸು = ಸಿದ್ಧಿಸು ( ೨ )  
ಥಳಥಳ + ಇಸು = ಥಳಥಳಿಸು ( ೨ )  
ಫಮಫವಮ + ಇಸು = ಘಮಫವಿಸು ( ೨ )  
ಪ್ರತ್ಯಯಾಂತ ಧಾತುಗಳು ಆಖ್ಯಾತ ಪ್ರತ್ಯಯಗಳನ್ನು ಹೊಂದಿ  
ಕ್ರಿಯಾಪದಗಳಾಗುವುವು.  
ಉದಾ : ಕನ್ನಡಿಸು + ಉತ್ತ + ಆನೆ = ಕನ್ನಡಿಸುತ್ತಾರೆ  
ಸಿದ್ಧಿಸು + ಇದೆ = ಸಿದ್ಧಿಸಿತು  
ಥಳಥಳಿಸು + ಉದು + ಥಳಥಳಿಸುವುದು  
ಅಕರ್ಮಕ ಸಕರ್ಮಕ ಧಾತುಗಳು :  
□ ಧಾತುಗಳಲ್ಲಿ ಎರಡು ವಿಧ. ಆ ಎರಡು ವಿಧಗಳು ಯಾವುವೆಂದು,  
(೧) ಅಕರ್ಮಕ ಧಾತು ಮತ್ತು (೨) ಸಕರ್ಮಕ ಧಾತು.
