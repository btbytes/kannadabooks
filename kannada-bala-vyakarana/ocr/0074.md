ಇದು ನಾಮಪದ:  
ಧಾತುಗಳಿಗೆ ಕೃತ್‌ ಪ್ರತ್ಯಯ ಸೇರಿ ಆಗುವ ಶಬ್ದವೇ ಕೃದಂತ,  
ಇದನ್ನು ಕೃದಂತ ನಾಮಪ್ರಕೃತಿ ಅಥವಾ ಕೃನ್ನಾಮ ಪ್ರಕೃತಿ ಎಂದು  
ಕರೆಯುವುದು ವಾಡಿಕೆ. ಈ ರೀತಿಯಾಗಿ ನಾಮಪ್ರಕೃತಿಗಳಿಗೆ ನಾಮ ವಿಭಕ್ತಿ  
ಪ್ರತ್ಯಯಗಳು ಸೇರಿ ನಾಮಪದಗಳಾಗುವುದು; ಇವೇ ಕೃದಂತ ನಾಮಪದಗಳು.  
ಉದಾಹರಣೆಗೆ :  
| ಓಡುವ + ಅವನು + ಉ = ಓಡುವವನು |  
| --- |  
| ಓಡುವ + ಅವನು + ಅನ್ನು = ಓಡುವವನನ್ನು |  
| ಓಡುವ + ಅವನು + ಇಂದ = ಓಡುವವನಿಂದ |  
| ಓಡುವ + ಅವನು + ಇಗೆ = ಓಡುವವನಿಗೆ |  
| ಓಡುವ + ಅವನು + ದೆಸೆಯಿಂದ = ಓಡುವವನದೆಸೆಯಿಂದ |  
| ಓಡುವ + ಅವನು + ಅ = ಓಡುವವನ |  
| ಓಡುವ + ಅವನು + ಅಲ್ಲಿ = ಓಡುವವನಲ್ಲಿ |  
| ಓಡುವ + ಅವನು + ಏ = ಓಡುವವನೇ |  

ಮೇಲಿನ ಉದಾಹರಣೆಯಲ್ಲಿ ಕೃದಂತ ನಾಮಪ್ರಕೃತಿಗೂ ನಾಮ ವಿಭಕ್ತಿ  
ಪ್ರತ್ಯಯಕ್ಕೂ ನಡುವೆ “ಅವನು” ಎಂಬ ಸರ್ವನಾಮ ಆಗಮವಾದುದು.  
ಇದೇ ರೀತಿಯಾಗಿ, ಸ್ತ್ರೀಲಿಂಗ ಏಕವಚನದಲ್ಲಿ “ಅವಳು”  
ಮತ್ತು ನಪುಂಸಕಲಿಂಗ ಏಕವಚನದಲ್ಲಿ “ಅದು” ಎಂಬ ಸರ್ವನಾಮಗಳು  
ಬರುವುದು.  

□ ಇದರ ಸಹಾಯದಿಂದ ನಾಮಪದಗಳನ್ನು ವಿಶೇಷಿಸುತ್ತಾರೆ.  
ಉದಾಹರಣೆಗಳಿಂದ ತಿಳಿಯಬಹುದು:  
- ಮಾ ಅಸ... (ಭೂತ ಕೃದಂತ)  
- ಹಾ ಬಾರಿ... (ಭವಿಷ್ಯತ್‌ ಕೃದಂತ)  
- ಸೂಚಕೆ; ಓಡ (ನಿಷೇಧ ಕೃದಂತ)  

ನಿಷೇಧಾರ್ಥ ಸೂಚನೆ: “ಓಡದ” ಇಲ್ಲಿ “ಅದ” ಎಂಬುದು.
