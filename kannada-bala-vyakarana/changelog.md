# Changelog

## 2026-11-01
- Created `convert_pages.py` to convert `kannada-bala-vyakarana.pdf` into web-efficient WebP images (`thumb/`, `full/`, `bw/`) and built the gallery/page reader in `index.html`.
- Created `ocr_pages.py` to extract Kannada Markdown for all 116 pages into `ocr/0001.md`–`ocr/0116.md` using `Qwen2.5-VL-32B-Instruct-GGUF` on Unsloth Studio with local Tesseract line anchors.
- Created `build_latex.py` and generated the A5-sized LaTeX book `kbv.tex` (and compiled `kbv.pdf`) from `ocr/*.md`, using `coverpage.png` as the cover and preserving the original page numbers.
- Added `Makefile` to compile `kbv.tex` into `kbv.pdf` with `xelatex` and clean up intermediate TeX build files.
- Changed `kbv.tex` page dimensions to 5in x 7in and recompiled `kbv.pdf`.
- Reformatted page 116 in `kbv.tex` as the back cover page matching `full/0116.webp` (framed notice box, indented paragraphs, and bottom title/price footer) and exported `backcoverpage.png`.
- Recreated the front cover page in `kbv.tex` using native TikZ and TeX elements (full-bleed red canvas, horizontal rules, double-ring scalloped cloud badge, outlined Kannada display title, vector peacock publisher logo, and bottom sinusoidal wave ribbons).
- Changed chapter and section heading fonts in `build_latex.py` from Noto Serif Kannada (fake bold) to Noto Sans Kannada Bold; body text stays Noto Serif Kannada. Regenerated `kbv.tex` and `kbv.pdf`.
- Fixed OCR typos across all pages `ocr/0001.md`–`ocr/0116.md` using Kannada vocabulary knowledge (ಸ/ಪ, ನ/ವ, ಣ/ನ, ಖು→ಋ, ಹೆ→ಹ confusions, wrong vowel signs, garbled punctuation and sandhi signs, a few OCR noise lines); Markdown structure and tables unchanged. Regenerated `kbv.tex` and `kbv.pdf`.
- Redesigned page layout in `build_latex.py` (regenerated `kbv.tex`/`kbv.pdf`): red accent palette matching the cover, chapter openers with lesson badge and rule, running header with chapter name and page tab, exercise strips with pen icon, rule boxes for ವ್ಯಾಖ್ಯೆ/ಸೂತ್ರ and □ rules, note boxes for ವಿವರಣೆ/ಗಮನಿಸಿ, pill labels for ಉದಾ, tinted derivation cards with the result word highlighted, zebra tables with accent headers, coloured vowels in the alphabet chart, verse blocks, bulleted proverbs, text top-aligned instead of stretched. Added a Latin fallback font so (i)/(ii) and the U metre marks render, dropped quote-only OCR lines, and fixed exercise-heading detection broken by the typo fixes. Page-to-page mapping unchanged.
- Added the reflowed edition `kbv-redux.tex` (generated by `build_latex.py` alongside `kbv.tex`): 6x9in two-sided pages, 11pt body with wider leading, chapters start on a fresh page and feed a generated table of contents and running heads, paragraphs split by the old page breaks are rejoined, derivation tables shrink to the text width. Makefile: `make redux` builds `kbv-redux.pdf` (two passes), `make redux-crop` builds `kbv-redux-crop.pdf` with trim marks on a 7x10in sheet. Shared cover, fonts and design macros were factored out of the page-faithful generator, which still reproduces `kbv.tex` unchanged. Raised header height in both editions so the page tab fits.
- Switched fonts: body text now Tiro Kannada, cover and chapter titles Baloo Tamma 2 (both SIL OFL, vendored in `fonts/` with static Baloo weights instanced from the variable font); Noto Sans Kannada stays for labels and heads. Latin fallback now comes from Tiro Kannada. Removed breakable boxes from the reflowed edition because they made following paragraphs render invisibly under XeTeX.
- Interior design made monochrome and plain in both editions: grey panels and hairlines replace the red accents, left bars, coloured badges, pills and icons; page numbers are plain; vowels in the alphabet chart are bold instead of red; all example labels (ಉದಾಹರಣೆ, ಉದಾಹರಣೆಗೆ) are normalised to "ಉದಾ :". The red cover is unchanged.
- Page-faithful `kbv.tex`: body set at 10pt/13pt with 9.5mm side margins and a tighter paragraph gap so the wider Tiro Kannada fits; still 116 pages with the original page mapping, and the number of auto-shrunk pages dropped from 89 to 73.
- Printed page 103 (ಷಟ್ಪದಿಗಳ ಲಕ್ಷಣಗಳು): replaced the rotated, shrunken table with an upright four-column table across the full text width in both editions; it now fills the page at near full size.
- Removed the light grey panels behind □ rule lines, ವ್ಯಾಖ್ಯೆ/ಸೂತ್ರ blocks, derivation blocks and table zebra rows; all backgrounds are now white.
- ಛಂದಸ್ಸು chapter and later pages: laghu marks (U, ∪, OCR garble) are typeset as \smile and guru marks (dashes, underscores) as a macron, in prose, prastara lines, the gana table and the ಷಟ್ಪದಿ table.
- Laghu mark changed from \smile to a deep U (\cup scaled to 0.85) so it matches the macron guru mark in height and weight.
- `make` with no target now prints the help; the old default build moved to `make book`.
- Source of truth moved from `ocr/*.md` to per-page `tex/NNNN.tex` files (113 files, exported once with `python3 build_latex.py --from-ocr`). `build_latex.py` now only assembles `kbv.tex` and `kbv-redux.tex` by `\input`-ing those files, so pages can be edited directly in TeX. Paragraphs cut by the original page breaks are marked with `\kbvcontinues`/`\kbvcontinued`, which the page-faithful edition ends and the reflowed edition joins. Makefile: `make tex` assembles, `make tex-from-ocr` re-exports (overwrites edits); PDFs depend on `tex/*.tex`.
- Page 10 (`tex/0012.tex`): added the traditional names of the vowel signs (ತಲೆಕಟ್ಟು, ದೀರ್ಘ, ಗುಡಿಸು, ಕೊಂಬು, ಋತ್ವ, ಏತ್ವ, ಐತ್ವ, ಒತ್ವ, ಓತ್ವ, ಔತ್ವ, ಅನುಸ್ವಾರ, ವಿಸರ್ಗ) to the ಕಾಗುಣಿತ table; fixed the example line (ಗ, ಗಾ, ಗಿ, ಗೀ).
